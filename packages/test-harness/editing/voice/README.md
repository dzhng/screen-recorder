# Generated-voice inputs

The [case owner](cases.json) binds supplied reference audio and requested text
used by the voice entry and relocation checks. The [production worker](../../../../helpers/voice/README.md)
owns execution and model identity. Exact settings belong to the consuming runner.

Identical reference bytes copied to several paths test path independence; they
cannot prove asset retention after a project is deleted. A generator returning
samples does not prove that requested words, voice identity or surrounding speech
were preserved. Numeric level matching likewise cannot substitute for listening.

Preserve original samples and distinguish raw output from measured or assembled
derivatives, so a cleanup step cannot silently create the claimed quality result.

The surrounding voice journeys in the [editing source](../) exercise runtime
entry, managed references, public delivery and relocation. Follow the selected
runner for prerequisites and resource ownership. Prepare models deliberately,
reuse valid outputs for scoring, and keep historical findings with their
[frozen evidence](../../../../specs/done/agent-editing/assets/README.md) rather than
treating experiment settings as product defaults.
