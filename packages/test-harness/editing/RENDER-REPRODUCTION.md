# Native rendering reproduction

The [current movie journey](video.mjs) verifies the admitted composition through
the native executor. The [standalone platform reference](RenderReproduction.swift)
remains an independent operand for [profile parity](video-profile-parity.mjs).
Invocation and case selection belong to those owners.

## Sample support is the temporal reference

A source sample occupies its declared support, not an assumed interval extending
to the next timestamp. Map sample clocks through edit-list segments before
selecting project pictures. A preview beginning inside a frame retains that
frame's original phase and clips its visible duration; it must not invent a new
frame grid at the preview origin.

Empty edits and unavailable acquisition are different conditions. A black output
may be correct for one and fabricated evidence for the other. The
[frame-membership oracle](render-membership.mjs) distinguishes labeled fixture
pictures from empty output, with explicit codec tolerance. It is an observer for
this corpus, not a general photographic classifier.

The [composition owner](../../composition/README.md) defines production time and
layer semantics. This probe has a narrower input domain; unsupported cases must
remain explicit rather than silently selecting another picture or rounding stored
coordinates to fit the experiment. It is a reference mechanism, not a second
product authoring or rendering model.

## Keep preservation claims separate

Authored frame membership, held duration and preview phase establish temporal
behavior. Independent PCM establishes source selection, placement and gain before
encoding. Codec output, resource cost and listening require their own observations.
Identical source bytes alone do not prove a correct project mapping.

The [color reproduction](COLOR-REPRODUCTION.md) owns source interpretation and
encoding-loss distinctions. Separately tagged synthetic inputs express a known
fixture interpretation; that assumption must not be applied to arbitrary camera
footage.

Exact operands, measurements and adoption boundaries live in the
[frozen rendering evidence](../../../specs/done/agent-editing/assets/06-render/report.json)
and [platform-rate reproduction](../../../specs/done/agent-editing/assets/06-platform-temporal/README.md).
Read those scopes before reusing a pass for another frame clock, layout or encoding
policy. Production integration must preserve the relevant result through its own
compiled and public boundaries. Historical experiment producers are available at
their [recorded source revision](../../../specs/done/agent-editing/assets/README.md).
