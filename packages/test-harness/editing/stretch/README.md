# Time and pitch references

The [Signalsmith reference](Signalsmith.cpp) isolates the adopted algorithm from project compilation,
managed preparation and publication. They supply independent recipe references
for the surrounding acoustic experiments and native parity checks. The
[production dependency](../../../../helpers/stretch/README.md) owns the adopted
library, vendored bytes and native file seam.

Match source samples, selected context and endpoint policy before comparing
recipes. Processing a short requested output and processing a complete state
domain are different experiments. Pitch preservation, exact duration, transient
placement and endpoint quality can disagree; none alone certifies natural speech.
Stereo comparisons must retain channel identity and shared time placement.

The reference and its importing runners own case selection, arguments and
preparation. Freeze the executable and reference inputs with their result before
using that result as an adoption baseline. Numerical parity preserves a measured
recipe; it does not select a new algorithm or prove public lifecycle behavior.

Keep independently consumed recipe references here. Completed alternative-algorithm
experiments belong to [historical evidence](../../../../specs/done/agent-editing/assets/README.md).
Production uses its
existing retime owner, and managed-job, cancellation and delivery checks belong
at that boundary rather than inside an alternative research renderer.
