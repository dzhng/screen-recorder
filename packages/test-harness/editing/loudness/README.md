# Loudness authority

This harness separates standards arithmetic from the public selection contract.
The independent oracle uses pinned libebur128 source, including its own FIR peak
interpolator. It does not use FFmpeg's scanner to certify itself. Build the C
wrapper against the source identity in the frozen protocol, in private scratch;
its arguments are an explicit Float32 PCM path, channel count and sample rate.
It accepts little-endian host PCM on the required Apple Silicon platform.

The measurement producer compares bounded authored signals and preserves complete
operands before gates. Its source owns invocation and cases. Freeze comparison
limits before confirmation. Smooth signals and abrupt boundaries are different
claims: agreement on the former cannot erase the retained resampler disagreement
on the latter. The spec owns actual measurements and supported scope.

The public journey uses the shared scratch service/CLI/MCP fixture, an explicitly
selected bundled FFmpeg distribution and a pinned native worker. It proves signal
selection, channel interpretation, null gating results and retained preparation.
It never plays audio or changes a personal library. Its source owns arguments;
`SCREENREC_NATIVE` pins the native executable. Generated sources remain intact.
Neither journey establishes universal meter compliance or subjective sound quality.
