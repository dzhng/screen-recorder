# Preserve fixture contracts through owner removal

Deleting obsolete recording-edit setup must preserve the guarantees it happened
to test. These checkpoints put archive lifetimes and publication recovery on
actual project/source owners before the old package and span families disappear.
The [publication contract map](publication-contract-map.md) distinguishes
transferred guarantees from outstanding ports and obsolete recording semantics.
It is a deletion prerequisite, not a claim that the old suite passes.

The registry pass uses canonical project manifests and the existing resource
resolver. Archive admission, independent handle ownership, cancellation, native
child drain and namespace revocation retain their existing meaning. Correctly
hashed malformed project metadata is refused before readiness; the removed lazy
recording-source interpretation has an explicit disposition. Generic archive
types no longer silently mean a recording manifest. Pending recording callers
name that type until their mapped removal.

The [registry report](registry-verification.json) pins reviewed source blobs,
the [original evidence](registry-evidence.tar.gz), actual terminal runs and
failure controls. All 14 cases pass. Original setup failures and the ineffective
mutation attempt remain separate from the decisive revocation failure control.
Root checked every archived payload and final source against the committed tree.
Emitted registry/archive code is unchanged by the type-only production edits.

The [publication report](publication-verification.json) and
[evidence archive](publication-evidence.tar.gz) retain the original combined
41-case green, final reviewed sources and transferred fault contracts. Actual
process-death boundaries and native receipt failures exercise the existing
publication primitive. Individual mutation results were transcribed from tool
outputs; native hashes were observed retrospectively. They are explicitly not
a contemporaneous process journal. Root verified all archived payloads and the
six committed source blobs without repeating these checks.

The [later publication lifetime bank](publication-lifetime-verification.json)

Early post-restart individual results are transcribed; subsequent logs are

The affected cohort passes 28 cases before a cleanup review repair; the final

Remaining abandonment resource-reference clauses, normalized acquisition-member
mutation, real package frame/audio failure retry and worker drain, and actual
bundled startup ordering must be accounted for before the old fixture and package
family can be removed. Aggregate library storage replaces the obsolete
per-recording allocation query; external committed files remain excluded.
Neither port changes that storage policy.

Fixture media bytes and probe results are controlled; filesystem/archive and
canonical metadata owners are real. These checks do not prove media decoding,
rendering, listening or installed behavior. No source recording, accepted
audition, native worker or installed library changed.
