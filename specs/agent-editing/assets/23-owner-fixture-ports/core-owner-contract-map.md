# Recording owner closure

Capture facts and project editorial state are separate durable owners. Removing
recording revisions retires their interpreter, original-revision preparation
policy and error producer; it does not retire capture lifecycle, raw evidence or
project edits. Frozen old source and test inputs are retained in the adjacent
evidence archive.

| Removed surface | Continuing contract owner | Retired scope |
| --- | --- | --- |
| Recording revision storage and replay | CaptureStore for allocation, lifecycle, diagnostics, discovery, rollback and deletion; ProjectStore for edit/history/replay/undo/concurrency | Recording-scoped edits and original revisions |
| Recording span interpreter | Composition edits/project evidence for current mapping and partial words; presentation-evidence/trails for raw geometry and retained pointer intervals | Nearest recording picture and recording-specific span policy |
| Recording SourceProcessing | CaptureSources/acquisitions for deferred source admission, explicit retry, workspace recovery and donor leases; source evidence store for indexed reclaim/cancellation | Automatic original-revision backfill and recording derivative cleanup |
| Backfill/busy observer | Current queue admission/capacity/capture priority and fenced cancellation; explicit source retry | Queue method used solely by the removed recording processor |
| Current recording response field | CaptureStore schema/query/type, public capture service and camera callers | A null editorial field in capture facts |
| Historical state-only caller | Exact final harness and producer closure in the 23j evidence archive | Maintaining recording-service calls as current runtime code |

The new catalog refuses prior formats before owner DDL. The [frozen prior
catalog](../../../../packages/core/fixtures/README.md) with cut/trim, replay receipts and undo state proves byte preservation.
Project revision fields and source receipt provenance are unchanged.

The named source, capture, project and evidence suites already own their
contracts; this pass does not clone their cases or reinterpret an old processing
cleanup policy as acquisition lifetime. Focused checks establish their stated
scope. Actual native movie/scene/index/worker lifetime, installed switching,
physical and listening gates remain separate.
