# Bounded evidence continuation work

The [baseline](baseline.json) records a real public phrase-search latency failure
and measured amplification in the existing query owners. Exact matches, clocks,
CLI parity and continuations pass; the existing cached latency budget fails.
The [red archive](red-evidence.tar.gz) preserves the diagnostic, authored revision,
frozen word fixture, all pages, runtime identities and native-call logs. The
[profile archive](profile-evidence.tar.gz) preserves authenticated in-memory timing
hooks, full pages and disabled-instrumentation controls. Source inference is declared
fixture input rather than measured recognition quality.

Nested timing categories overlap: window projection is inside planning and source
reads are inside merging. Counters are measured, not inferred from source. The
profile's pass means hooks and values agree; it does not mean the latency budget
passes. The owning24x slice carries implementation and acceptance. No playback,
model preparation or product telemetry endpoint was used.
