# Remaining audio acceptance

The read-only [mixing/inspection audit](audio-inspection.md) separates finite
codec/rate and real-narration gaps from mechanisms already verified. The
[stretch audit](stretch.md) distinguishes binding preservation requirements from
research diagnostics; it does not convert measurements into listening approval.

adds a separate public real-narration preservation journey. Model-dependent
retiming follows independently judged speech evidence and the existing prepared
audio owner. These audits freeze their checkpoint; current integration status
lives in the implementation pickup. No new engine or policy is selected here.
