# Standalone project audio export evidence

The isolated public CLI/MCP journey passes for exact Float32 WAV and native
AAC/M4A. It uses caller-authored fixture operations and a pinned native worker;
it makes no editorial judgment and requests no personal recording or audition.
The [slice](../../slices/09c-audio-only-export.md) owns the product contract.
Installed cutover, general speech quality and performance remain separate claims.

`evidence.tar.gz` retains full public requests/replies, published media, decoded
samples, the closed catalog and actual native operation journal. The final cohort
is `public-complete`; `public-all-gates` records the resolved metadata omission.
The rejected native packet-capacity guard is preserved in
`public-reviewed-corrected`, with the exact rejected worker/source in the
[native FILE packet](../09c-native-audio-file/README.md). Diagnostic early runs
and the export-kind constraint mutant remain evidence of failures, not acceptance.

The WAV oracle independently derives every expected sample from the fixture's
explicit gain, split and trim. Keeping, removing and undoing video produce the
same separately retained audio. Later audio gain and changed AAC defaults cannot
change a frozen export. Publication checks exercise replay, occupied destinations,
cancel/retry, process restart and recovery, including a held real AAC completion
that is canceled before a fresh attempt commits. The operation journal excludes
visual preparation and video capability discovery. Audio export does not mutate
the project or original media.

AAC verification is separate from exact WAV parity. Container/decoder inspections
check one AAC track, rate/layout, zero origin, authored duration, channel mapping,
packet padding and protected endpoints under a recorded error bound. The native
packet covers the larger rendition/strategy matrix, whole-file conversion beyond
inspection limits, native refusal, cancellation and actual movie-mux preservation.
No additional codec is advertised on the basis of import support.

[source/runtime pins](source-runtime-pins.json) name the exact source, emitted
JavaScript and consumer test programs. [Module resolution](module-resolution.json)
records imports without constructing devices or models; [external runtime pins](external-runtime-pins.json)
retain the resolved JavaScript dependencies. External Node, FFmpeg and FFprobe
binaries plus their non-system linked libraries are preserved in
`external-tools.tar.gz`; [link outputs](external-tools-links.json) identify the
remaining macOS system dependencies. Native source and workers remain in their
separate immutable packet. The source archives are evidence, not installed builds.

[Verification](verification.json) records scope and final results; the
[review](review.md) and [choices](choices.md) explain the ownership and decisions.
`members.json` hashes each packet member, and `archive-verification.json` records
independent archive hash/count checks. Functional success supplies no latency,
peak-memory or hardware-quality verdict.
