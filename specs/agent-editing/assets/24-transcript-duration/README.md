# Transcript pages across timeline durations

Bounded transcript pages preserve their values and remain practical when empty
space makes a project longer. This checkpoint extends the existing duration-memory
runner with an explicit transcript case. It measures the service process across
matched two-/four-hour projects with identical occurrence and history counts.

[Independent root verification](verification.json) repeats all six trials after
integration. Each cached query follows four real MCP pages and verifies the complete
250-word result against independently authored occurrence clocks, including source
ranges, clip identities, confidence, partial flags and generation. CLI returns the
same rows. A one-microsecond wrong-clock control fails. The original timeline and
waveform cases retain their default behavior and budgets.

Median sampled peak and growth ratios remain near one; every cached query p95 is
below the existing250ms target. Cold reads are retained separately and exceed that
cached target. These are observations for this fixed-cardinality cohort, not a
universal latency or memory guarantee. Root and implementation runs agree despite
reported background host load; only service RSS is measured.

## Declared inference boundary

The native ASR output's first segment is copied unchanged, preserving its words,
timings and confidence. Its reduced receipt and original identities are retained.
Synthetic PCM supplies real admitted media support; this fixture does not claim
those samples were recognized as speech. A child-process model wrapper declares
readiness while checking the registered pins and model digest. No model is copied,
prepared or executed. Production admission, transcript ingestion/storage and public
querying remain real. A native-call allowlist catches decoding or repeated inference
during queries while permitting normal workspace cleanup.

[The evidence archive](evidence.tar.gz) retains the implementation run, exact
pages, source/runtime identities, wrong-clock control, review and explicit fixture
configuration. [Root evidence](root-evidence.tar.xz) retains the independent run's
pages and calls. The test harness owns these seams; no product API, dependency or
performance limit was added. Root and independent code review found no unresolved
issue. Configured Codex CLI review could not start and is not counted as a pass.
