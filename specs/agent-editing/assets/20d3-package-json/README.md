# Portable project JSON

A compact manifest identifies inventory members; it does not carry their full
metadata. The same admitted descriptor owner hydrates revision documents and existing
typed resources before schema, history, dependency and canonical-clock verification
can expose a ready package. Missing, changed or mislabeled JSON cannot authorize a
partial ready context. Recording packages keep their original extraction contract.

The unified serialized-JSON budget is an eager working-memory admission. The retained
near-boundary fixture measures the production descriptor resolver using actual public
history and canonical metadata plus repeated typed rows with synthetic identities.
It is not a native archive or media proof. Actual public journeys independently cover
large canonical metadata and complete public edit history after donor removal.

Export status reads a derived covering index rather than parsing the authoritative
execution snapshot. Retained measurements include the rejected noncovering index:
small replies alone did not remove the large-record read cost. Lifecycle updates pay
for the derived index; the checkpoint does not call this cost free.

`verification.json` records commands, outcomes and scope. `manifest.json` hashes the
retained artifacts in `evidence.tar.xz`, including red boundaries and exact successful
package members. These proofs do not establish listening quality, unrestricted lazy
package scale, or completion of the broader capture and editing plans.

[Integrated root verification](root-verification.json) confirms the focused and
real native owner/archive gates; [reports](root-verification.tar.gz) retain their output.
The combined fragmented-source/history journey remains a separate acceptance gate.
