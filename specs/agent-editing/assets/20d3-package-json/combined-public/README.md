# Combined fragmented-source package gate

The actual public workflow now combines a 100,000-run canonical source and 10,000
placed clips. Fresh catalog format 16 adoption uses the previously retained version 2
package; existing catalog format 15 homes remain unchanged. All edit requests retain their
original deadlines. Complete selected history and typed resource JSON travel through
inventory-bound members, followed by native canonical verification before readiness.

The gate compares every donor revision document to its archived document and every
adopted document to that archive, then checks undo against the prior document. It
compares every original typed resource to the combined export, all physical segment
rows after relocation, and the complete acquired-source metadata. The normalized
evidence file locator must move to the receiver's owned directory; every other field
is equal. Missing, corrupt, duplicate-stream and old-format archives never become ready.

The original first-batch product timeout and exact replay remain in the parent
checkpoint. This run separately retains an initial `/tmp` symlink setup refusal and
a mistaken harness expectation that a relocated evidence file kept its donor path.
After correcting that locator expectation, verification resumes the already-adopted
receiver without repeating setup or native admission. The report records this
continuation explicitly. It is not a product failure or a waived metadata comparison.

`verification.json` names the source, worker and inputs. `manifest.json` authenticates
all files in `evidence.tar.xz`, including the complete exported package, public pages,
metadata, reports and frozen continuation. Observed timings describe this workload;
there is no new DSP, audio-quality, listening, unbounded-package or whole-plan claim.
