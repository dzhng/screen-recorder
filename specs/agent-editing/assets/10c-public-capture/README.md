# Public capture evidence journey

[The capture journey](../../../../packages/test-harness/editing/capture-evidence.mjs)
uses real CLI and MCP calls around the project service. Capture adoption copies
media/journals, invokes native probing and normalization, and indexes observations
through the real source store. No database rows, source results or native replies
are substituted. The service wrapper only records actual indexed reads and returns
their original rows.

The [fixture owner](../../../../packages/test-harness/editing/capture-evidence-fixture.mjs)
uses the retained narrated recording in two ways: its original journal supplies a
real-observation case, and explicitly synthetic journals supply populated pauses,
untimed geometry, empty evidence and an incomplete tail. A native passthrough video
fixture introduces a container offset and physical empty edit without activating
capture or playing media. Every imported normalized file must byte-match the
independent native normalization of its admitted journal.

The oracle follows a fixed authored placement plan with independent exact rational
arithmetic. Returned rows must retain original coordinates, eligibility, normalized
source sequence and separate capture/asset/project clocks. A repeated source is a
new occurrence, equal starts remain ordered by track, and retiming must preserve
fractional timestamps. Synthetic pauses distinguish acquired speech support from a
continuous physical audio file. Missing context, valid empty observations, unsupported
categories and missing support are separate assertions.

Continuation checks exercise limits, query/domain/context refusal, historical reads
after head changes and restart, and actual checkpoint file loss. This is file-loss
acceptance, not a claim of forced LRU eviction. A crowded project requires an empty
initialization continuation, bounds each page's real reads, and avoids repeated
source prefixes. A late real-journal window reads only its relevant geometry rows.

The preserved report and complete row oracles describe the verified run and record
runtime/native hashes. All gates passed. Clock mutation breaks exact row matching;
eager-read mutation returns unchanged correct observations but fails the real-read
count. The restored runtime passes again. The retained normalized synthetic fixtures
and native receipts distinguish controlled test data from physical capture evidence.

Source scenes, project-cut meaning and interruption inspection remain explicitly
unsupported and are still implementation pickup work. This journey does not close
those categories or the complete editor spec.

Independent Codex review found no actionable defects and checked all three
JavaScript modules syntactically; it did not rerun the native journey. Formatting,
lint and diff checks pass. The final retained run is the restored runtime after
both falsifications, with compact read telemetry that leaves source results intact.
