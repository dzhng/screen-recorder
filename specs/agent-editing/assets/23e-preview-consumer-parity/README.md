# Native preview receipt and lease consumption

The native preview keeps one request/receipt/lease owner. Its concrete AppKit/AV
presenter receives only validated presentation requests and forwards user/player
events. Ordinary user-requested recording playback remains in that presenter.
Explicit project targets use the existing preview operations and project liveness
lookup; the recording menu remains a recording caller. Shared native target
decoding also preserves the 23d export consumer without compatibility aliases.

[Verification](verification.json) and [the packet](evidence.tar.gz) preserve the
controlled public-receipt check. The first headless tracer ran after presentation
extraction but before target porting, and failed because the controller still
sent a recording target for project input. The final controller accepts the
unchanged retained processing/ready payload values, pins the first revision and
passes the exact file/MIME request to a non-rendering sink. Explicit revision,
outer/movie target, byte count, lease and path mismatches fail before presentation.

Controlled replies and clock advances establish renewal past original expiry,
owner deletion, expiry/refused renewal, explicit retry/dependency behavior,
same-ID namespace isolation, late delivery and stale presentation callbacks.
Removing the post-renewal generation fence makes a replacement session release
the old token instead of its own; that targeted mutation failed and the restored
source passed. No second request/lease state machine is used by the tests.

The clock is a default-real-time external boundary. The saved project receipts
are decoded with a frozen clock before their historical expiry; their original
files are retained byte for byte. No saved token contacts a real service and no
saved cache pathname is opened. Scripted owner, failure and renewal variations
are labeled controls, not new capture or media evidence.

The three focused headless controller checks and all pure-controls groups pass.
The two original AVPlayer/bundled-service Swift fixtures also compile against the
real presenter and controller, retaining their existing assertions and ordinary
suite selection. Their executables were deliberately not launched. Source review
preserves native window properties, MIME-directed asset creation, playback and
close cleanup; this does not claim new playback or visual verification.

[The manifest](manifest.json) pins current source, retained references and every
regular packet member. Root independent source review is clean; the configured
unavailable CLI reviewer was not retried. All owned checks exited and their scratch
build directories were removed. No media render, service run, device/capture work,
model work, audible output, application launch or installed switch ran. Remaining
project-selection and final installed acceptance belong to parent 23.
