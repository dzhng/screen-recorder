# Project-native editorial cuts

Composition derives editorial mapping transitions from the full pinned revision.
Core merges these rows with captured and measured evidence using the existing
manifest, bounded heap and cache checkpoints. An exact cut is a reason to inspect
nearby media; it is not evidence of a pixel or waveform discontinuity. Physical
support gaps retain their separate availability meaning.

The [authored public journey](public/report.json) exercises actual CLI/MCP, native
asset probing and source scene preparation. Its [complete results](public/project.json)
preserve replacements, overlays, separate audio boundaries, held pictures, silence,
continuous-source rate changes, exact fractional anchored boundaries, split invariance,
query ownership and historical continuation after restart. The source is the existing
[authored physical-gap fixture](../10d-public-scenes/authored-source.mov); no screen
capture, speaker playback or installation occurs.

[Capture preservation](capture-preservation/report.json) compares complete source
and projected observation rows with independent authored expectations, including
cut ties and interruption endpoints. [Scene preservation](scene-preservation/report.json)
retains actual scene sampling, capture mixing, cancellation/retry, source gaps and
repeated/retimed occurrences. All use the frozen native worker hash recorded in each
report. Cut rows have revision authority; source generation remains on source rows.
The original real journal stays in the narrated-workbench fixture; native receipts
retain its normalization hash without duplicating the full observation log here.

[Frozen transcript preservation](transcript-preservation/report.json) repeats the actual
public paging/phrase/acquired-gap journey on the same runtime. The
[runtime agreement](runtime-agreement.json) verifies every recorded module and native
hash against this checkout. Source ASR responses alone are frozen.

The pure suite covers exact fractional seams and true terminal exclusion, identical
holds/silence, same-rate continuity, rate changes and support holes. Real-store core
coverage verifies cut-only projects and source regeneration: old combined event
cursors refuse changed evidence, while a fresh query produces identical cut rows.

## Review and verification

The initial pure contract test failed because no selector existed, then passed
through the implemented public composition seam. Independent Codex review found no
actionable defects in timing, continuity, ordering, paging or bounded work; it was
read-only and did not execute the native journeys. Shape review retained one exact
mapping owner and reused existing lifecycle; diff review preserved original source
row order; docs distinguish implemented cuts from remaining whole-slice acceptance.

The full core suite passes 571 tests with one pre-existing skip; composition passes
125 and protocol passes 18. CLI/service dependency builds and type checks pass.
[Core tests](core-tests.txt), [protocol tests](protocol-tests.txt), [type checks](types.txt)
and the [targeted build](build.txt) retain the final verification. The
[compiled-only negative control](mutation.json) drops only cut iterator rows and
makes the actual public oracle fail; restoring that runtime passes the journey again. No native rendering capability
or source-index acceptance follows from this event-only change.

The [integrated root confirmation](integrated.json) reruns the actual public cut
journey after merging the compiler frame-boundary seam. All authored checks pass,
as do 59 focused compiler/cut/project-evidence tests and CLI/service dependency
builds. Public changed-generation verification remains the separate gate above.
