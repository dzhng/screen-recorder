# Public source frame journey choices

- Reuse the existing scratch service and actual import paths. A synthetic capture
  journal is adopted through public acquisition import; no private table writes
  manufacture video masks that the public contract does not admit.
- Compare displayed meaning through an independent CoreGraphics sRGB RGBA oracle.
  Raw RGB equality ignores the profile and can accept a visibly different PNG.
  Preserve alpha admission and exact comparison; no tolerance hides delivery drift.
- Preserve the native reference visual review by exact public pixel equality.
  New source/index/still-image coverage is not inferred from demanded timed frames.
- Keep cancellation deterministic at the existing native reply barrier: it holds
  a real result while the public job is canceled, rather than mocking rendering.
