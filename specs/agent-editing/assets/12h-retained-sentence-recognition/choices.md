# Retained-sentence case choices

## Sound

- **Case isolation — high confidence.** When the historical recognizer misses a
  human-confirmed filler, run only the existing entire sentence as a separate
  diagnostic. The plan leaves the producer packaging open. Reusing the existing
  model owner and frozen worker avoids a second recognition implementation or
  recipe. This creates no product API, editorial rule or baseline change.
- **Source clock — high confidence.** A word at WAV time zero belongs at original
  source time 50.518675 seconds. Request the WAV in its own clock and add that
  binding exactly once during evaluation. The plan permits equivalent request
  clock encodings; using local time keeps the mapping explicit and prevents an
  accidental second addition of the recording's origin.
- **Evidence storage — high confidence.** Bank complete compact outputs and
  identity receipts; reference retained media/model authorities instead of
  duplicating weights or originals. Storage names are delegated. Preserve actual
  runtime and model homes so future inspection can distinguish executing bytes
  from a later verifier, without making archive packaging a new model run.
