# Registered Parakeet readiness

The [23n checker](../../../../packages/test-harness/editing/parakeet-readiness.mjs)
prepared the selected registered transcription model through the genuine public
model owner in an isolated library. The named historical source and exact default
HF snapshot were absent. HF CLI acquired only the registered files at the pinned
revision, and every byte count/hash and the model-card license notice matched.
Public preparation created its own managed files and receipt; none were copied
from another library or fabricated.

CLI and default SDK MCP requests observed absent, shared preparing state, monotonic
progress, ready reuse and ready state after service reopen. The actual Models
owner returned the managed execution directory and complete registered file list.
Both source services, both SDK children, both startup fences and both frozen
native children have actual terminal events. The only forwarded native operation
was media.audioCapabilities; no transcription or other media operation ran.

[Verification](verification.json) names the retained source, home and source
runtime for 23m. They remain outside Git. The packet banks the exact receipt,
complete operation replies, actual producer versions, commands and byte identities.
The ready report's preservation fingerprint hashes compact JSON of the ordered
snapshot object; archive member hashes independently cover exact saved file bytes.
The before/after equality covers original Qwen source/runtime, both named prepared
homes/receipts and present named workers. No Qwen preparation or inference repeated.

Original setup failures remain distinct: missing package-local external links
caused the first TypeScript build failure; HF rejected conflicting cache/local-dir
flags; the runtime verifier refused a /tmp alias; and a discovery expectation used
the model ID where the existing owner returns its repository identity. Only setup
or checker inputs changed. The discovery attempt's identical preservation snapshot
shares one archived byte authority with the final gate instead of duplicating it.

[Choices](choices.md) records the evidence/storage decisions. No product owner,
model selection, runtime recipe, API, limit or deadline changed. This establishes
metadata readiness, not new ASR quality, inference, installed readiness or full
12/23/25 acceptance. Root independently rehashed managed files and receipt before
starting the separate 23m consumer pass; that does not expand this packet's scope.
