# Bounded lexical-reference qualification

The [qualification](qualification.json) pins one official Earnings21 pair and
its missing prerequisites. [Verification](verification.json) independently checks
reference identity, filler counts and absent usable timestamps. The [archive](evidence.tar.gz)
retains the primary metadata/text and [member hashes](members.json).

This source does not currently supply a complete short audio/reference interval.
It establishes no recognition score, independent word edges or selected-model
pretraining exclusion. The candidate is closed for this bounded pass; do not
repeat the same metadata search or manufacture a timed crop from token position.
Continue other primitive work. A later lexical experiment needs a named source
whose complete context interval and applicable use authority are established.

Retained reference text and alignment metadata originate from
[Rev's speech-datasets](https://github.com/revdotcom/speech-datasets/tree/c05ab6fd8b4b627d123c922a22a39e993dd37635/earnings21).
They retain the publisher's [CC BY-SA 4.0 text license](https://github.com/revdotcom/speech-datasets/blob/c05ab6fd8b4b627d123c922a22a39e993dd37635/earnings21/LICENSE.md),
also included in the archive. Audio bytes are not included; inspected metadata
supplies no matching blanket audio grant.
