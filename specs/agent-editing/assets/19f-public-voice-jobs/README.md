# Public durable voice-job evidence

The public journey uses the released 19d preparation and the real service/native
boundary. It never prepares or copies a model. `report.json` records the final
saved-output/context/package pass; its prerequisite is the complete first execution
run retained in the archive. Later passes reused saved outputs, not new synthesis.

The full unchanged word and phrase WAVs match the frozen 18 files exactly. Six
bounded synthesis attempts cover direct completion, cancellation after completed
worker output but before asset publication, explicit retry, service crash at the same
boundary, changed-seed/top-p retry, and forced token-budget failure. Published EOS
receipts report 11, 42 and 27 generated tokens. The one-token attempt reports
`VOICE_INCOMPLETE`, `stopReason: token-budget` and no result asset. The canceled/crashed
attempts publish no catalog asset; their temporary output files are not retained.

The changed-setting result has 51,841 frames at 24kHz and rounded duration
2,160,042us. It disproves an assumed whole-microsecond codec quantum. The owner
preserves the worker's duration metadata policy and authoritative exact frames;
it does not change PCM, stretch audio or use a fitted tolerance.

[Root verification](root-verification.json) records combined build/tests and an
independent rehash of every archived evidence file after integration.

## Durable behavior

CLI/MCP replay agrees. Complete saved assets remain inspectable and exportable when
the model directory is absent; a new request returns `MODEL_NOT_PREPARED`. An actual
integer-PCM WAV is refused as `INVALID_REFERENCE` with extraction guidance before
synthesis. The selected reference origin is frozen explicitly; omission remains
none, and later unrelated origins do not enter identity.

Generated bytes and the actual reference asset survive public export/open/adopt in
a fresh model-free receiver. Ordinary replacement preserves clip processing and
picture bytes; explicit complementary original/voice overlap fades and a retained
original-room-tone layer render. Undo restores exact baseline audio. The report
names authored overlap ranges separately from protected join windows containing
resampling influence; all PCM beyond replacement plus those windows is exact.
Pronunciation, speaker identity, level, naturalness and audible joins remain separate
parent acceptance. No playback or listening was performed, and the inherited room-
tone pause is not independently established as speech-free.

A fresh Luna consumer used only the product skill, public Node CLI help, exact
request and receipts. It recovered 80,640 mono24k frames while model status was
absent, inspected the retained origin and exported audio. Its delivered WAV has the
inspection renderer's header, so its delivery hash is not presented as the immutable
generated-file hash. Every attempt, including a shell-status mistake, is retained.

## Review boundaries

Independent review found two real defects. A queued project voice request could run
before its owner existed; both services now use the queue's explicit execution
readiness barrier after recovery. A reordered tokenizer-identity map could alter a
selected origin's serialization; canonical typed field/record ordering now owns the
frozen snapshot. Controlled reversions reproduce `undefined.execute` and unwanted
`MODEL_NOT_PREPARED` replay respectively. The recording-service queued cleanup case
was green before the fix and remains preservation coverage, not a claimed old bug.

The archive also retains fixture failures: the initial overly narrow context
assertion, an omitted resume option, a syntax mistake and rejected same-track
overlap. The final fixture uses separate tracks and real complementary fades. No
failure is silently converted into a success claim.

`evidence.tar.gz` contains all attempts, WAVs, pictures, public requests/receipts,
focused test/build logs, review output and the fresh consumer. Its index records
SHA256 and byte count for every member; `verification.json` records rehash results,
worker/runtime identities and final gates. Shared excerpt, queue, capture/deletion,
asset, package, protocol and CLI preservation remain part of this checkpoint.

The broader shutdown suite exposed a catalog-writer race at post-start activation.
A real child-service probe located `STORAGE_BUSY` in queue claiming, rather than
recovery itself. The recording entry now logs only retryable activation errors
through its background-admission path; fatal errors stay visible. A focused queue
check releases the writer and proves ordinary scheduling then executes the durable
job exactly once. The original graceful-EOF/catalog-lock assertions and deadlines
remain unchanged;
its external writer now waits a bounded second to acquire the intended lock before
EOF, because startup availability does not promise catalog quiescence. This test-
fixture synchronization is not a production retry or timeout policy.

The final independent review reported no actionable regressions and passed all 79
focused queue/voice tests. Its service tests could not bind sockets in its sandbox;
the separate real-service preservation run passed all 98 tests. The final record-
ordering regression covers both reordered caller input and addition of an equivalent
stored origin, with saved replay succeeding while model readiness is unavailable.
