fetch boundary serves unchanged verified installed bytes; no live network
transfer or inference is claimed. Personal model files and receipt remain
read-only and match the retained actual-inference identities.

native requests and reopen. [The public continuation](public-report.json) connects

and service reopen, with network access denied. Full descriptor and model
identity, receipt and prepared-file identities remain unchanged. Only the native
startup capabilities response is controlled at the existing worker boundary.

[The pinned archive](manifest.json) contains complete requests/results, file and
receipt identities, exact checkpoint programs, source/runtime archive and actual
Node resolution graph. Existing model-owner tests pass. Scratch copies and child
processes are cleaned after owner shutdown. Three full preparations are counted:
the owner checkpoint, a public attempt correctly refused because its scratch
library had 0755 permissions, and the corrected 0700 public checkpoint. The
failed attempt is retained; it is a harness error, not a product defect.

This closes generic owner preparation/readiness and its public ready-state
connection. Full absent-to-ready public download transport, live Hub availability,
speech quality, listening, alignment, inference latency and release acceptance
are outside this proof. Prior controlled public preparation states and the two
accepted actual inference attempts remain unchanged.
