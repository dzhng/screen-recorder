# Camera publication scheduling evidence

Complete native sample timing qualifies an intended export interval; it never
certifies decoded pictures. The existing ordered raw and canonical pixel scans
still certify publication. The production change overlaps those scans after a
private export and joins both before selecting a result.

[verification.json](verification.json) binds the executed source, commands,
modules, terminal processes and compact results. The known-picture/fractional,
generic-prefix, raw-first refusal, receipt continuation and conflict checks are
in [checks.stdout](checks.stdout). [cancellation.raw](cancellation.raw) records
actual cancellation after both SDK readers were reading, unchanged delegated
startReading calls, reader drain, restored implementation and no publication.
The observer exists only in this test process.

The prefix fixtures fail metadata qualification and therefore establish only the
generic raw-first path. Synthetic Result controls establish the production
arbitration decision, not physical interruption. The one damaged payload retained
identical native timing and raw bytes across old/current cases, but both decoders
returned all pictures. Its unchanged physical digest/support/count is parity
for that fully decodable case; it did not produce the required shorter physical
prefix after successful qualification. Separate authoring changes mapping/closed
JSON identities and exported movie bytes, so full receipt equality is not claimed.

Scheduling implementation is verified within those bounds. At this initial
checkpoint, qualified decoder interruption/premature EOF followed by fallback
publication remained unobserved;
retained-take adoption, working-memory cost and completed-stop latency remain
unverified. Original evidence and frozen workers are unchanged. Routine setup
failures and compiled scratch artifacts remain at the recorded outside-repo paths.

[Root integration](merged.json) independently checks all changed source bindings,
executed artifacts, packet payloads, terminal processes and complete physical
receipt fields. It repeats no native control or performance cohort.

The later [H264 supplement](h264-interruption/README.md) closes one real qualified
interruption/fallback case while retaining the original fully decodable damage
experiment and its limitations. The [retained metadata predicate](retained-eligibility/README.md)
also passes without decoder/publication dispatch. Actual full-take overlap,
resources and performance remain separate from these scoped proofs.
