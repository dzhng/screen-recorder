# Native cursor fact availability

**The retained closed movie exposes complete native sample metadata.** The saved
native inventory corresponds to every retained picture and accepted mapping on
the existing writer clock grid. Original exact clocks and flags stay separate;
rational correspondence does not erase rounding. Distinct, fixed-position cursors
from one track supply actual reordering answers.

[The report](report.json) separates observed facts from unknown meanings. Full
sync flags, dependency knowledge, decode duration, storage extents and reordering
are evidence for a future hypothesis; they do not establish an immutable prefix
during recording. The endpoint retains the existing owner's mapping/clipping of
SDK **decode duration**, not an independent display-duration guarantee.

[The manifest](manifest.json) pins the frozen source, unchanged qualified observer,
exact commands, runtime/input authority, binary, complete native rows, original
timing projection, logs and actual terminal receipts in the archive. Its frozen
saved-data checker compares every value and rejects altered membership/positions;
it performs no native replay. Original media and pixel tuples remain bound to the
physical packet. No production mechanism or maintained harness was added.
