# Retained-file range and digest authority

[The report](report.json) qualifies fixed range continuation for two independent
hash states. Every returned picture is retained once with absolute timestamps
and the existing endpoint owner. The exact CameraMedia digest body is projected
for this experiment; saved tuple bytes supply the checkpoints without another
complete native traversal or a second production digest owner.

[The manifest](manifest.json) preserves source, fixed plan, golden/projection,
complete decoded and compressed buffer facts, operands, reader EOFs, binary and
actual process/cache identities. Every archive member was read and rehashed;
standard tar hardlinks retain byte-identical members. Immutable movies stay
with their existing authorities.

Native range output and marker facts are observations. They establish no
compressed transfer/filtering policy, growing-asset refresh, internal decoder
preroll bound, live ownership, recovery or stop-time guarantee. Endpoints retain
SampleTiming's decode-duration/mapping-clipping meaning rather than ranged
buffer duration or an independent SDK display-duration guarantee.
