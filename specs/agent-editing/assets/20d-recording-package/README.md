# Canonical recording-package admission

Portable audio support must be derived from the same immutable media and publication proof as its source. A valid archive hash is insufficient: metadata and audio pages can be changed together and rehashed. Recording package assembly and transient package readiness now reuse the native source-admission owner used by project acquisitions, then compare the ordered audio pages consumed by recording reads against regenerated evidence. The package inventories each per-role publication receipt; omission or a claimed legacy layout cannot bypass verification.

The caller owns temporary verification lifetime. Native verification inherits its existing workspace lock descriptor, so service restart cannot reclaim that workspace while an orphan worker still owns it. This introduces no separate ready store or cleanup process. Project binding reconstruction stays with AcquisitionImporter; recording support comparisons stream through the existing evidence-page reader. Recording reads use the canonical file's native clock and fixed source offset, not a caller-supplied asset clock dictionary.

## Evidence

[verification.json](verification.json) identifies retained artifacts, their hashes and commands. The native worker is unchanged from [canonical admission](../20d-canonical-admission/README.md). The actual processed-package owner exports a prerecorded canonical source, then the donor source is removed. Reopened package audio matches the complete independently authored lossless waveform at its non-grid phase and separated native-frame runs. The speech prerequisite is an explicit fixture stub; this is no ASR, codec-quality, listening or live-capture result.

Missing receipt inventory, an actual-layout downgrade and altered/rehashed audio pages are refused before readiness. Removing the native readiness hook lets a missing-proof package reach ready, and the retained negative control fails. Removing the inherited lifetime descriptor fails the assembly gate; restoration passes. That gate checks a real live directory descriptor on both native verification paths, not a new process-death experiment. Existing narrated and no-narration packages and copy-change refusal remain covered. The shared acquisition/project regression retains public relocation/adoption and forged-clock refusals.

An early fixture lacked timed geometry and another assumed stereo where the recording reader correctly returns mono. Those harness errors are retained separately from product failures; the corrected oracle compares complete bytes without expensive deep-buffer diff formatting.

## Remaining rollout

This closes the recording-domain portable source-proof gap alongside the earlier project admission checkpoint. It does not activate packed capture callbacks or close the full publication slice. Typed zero-represented outcomes, writer/recovery integration, long-work operation-specific budgets and physical capture gates remain separate. Verification performs native work during package readiness; existing worker cancellation is retained, and the current short worker deadline is not claimed to cover the measured large fragmented workload.
