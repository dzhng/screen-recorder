# Intact-buffer container authority

[The report](report.json) qualifies one distinct passthrough MOV: original
reader buffers, including every marker, were forwarded unchanged. The
candidate's own committed prefix survives further active admission and closure;
the complete closed result matches the frozen input pictures, logical samples,
format and support. Media buffer facts compare every field except bufferOrdinal,
because container-generated marker counts can differ. Complete marker facts
and actual forwarding receipts remain separate evidence.

[The manifest](manifest.json) pins the exact source, plan, binary, complete
operands, copied movies, query/process terminals and protected cache checks.
Its archive uses standard tar hardlinks for byte-identical members; every member
was read and rehashed. Qualified source codec, native cursor and picture
authorities were reused. The original failed prototype remains unchanged.

This tiny mechanism pass does not execute either production digest or qualify
interruption, recovery, bounded backlog, sustained capture or the stop boundary.
No production mechanism is selected by this experiment.

[Root saved-data verification](merged.json) independently checks all archived
payloads, actual process terminals and the complete pixel, clock, encoded-byte,
support and buffer-fact comparisons. No native baseline is replayed.
