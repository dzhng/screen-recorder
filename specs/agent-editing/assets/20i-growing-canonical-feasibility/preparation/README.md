The [slice](../../../slices/20i-growing-canonical-feasibility.md) owns the fixed
question. [The report](report.json) separates source-only checks from the
unstarted compiler, process-ownership prerequisite and native movie case.

[The manifest](manifest.json) identifies a frozen reference archive: exact new
source and plan, existing qualified observation/codec functions, runtime bindings
and inspected SDK process-identity headers. These are experiment references,
not a maintained harness or a new product owner. The retained input movie and
complete decoded baseline remain with their existing 20g/20h authorities.

The plan preserves compressed input membership and compares the distinct
container against its own active prefix and every frozen input picture. The
source baseline receives a metadata/byte query, without another pixel decode.
Actual parent/group identity and terminal absence must pass the nonmedia
prerequisite before any media work. Source inspection establishes neither
process-cleanup behavior nor physical append stability.
