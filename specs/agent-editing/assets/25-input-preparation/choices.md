# Preparation choices

All entries are sound; no user-only editorial decision is required.

- **Medium confidence — prepare an empty project and admitted inputs.** The caller
  receives the exact requested canvas plus stable asset/clock bindings. It still
  chooses how to express the brief's operations. Prebuilding an edited tutorial
  would test the developer's calls and diminish the fresh caller's discovery gate.
- **High confidence — retain interrupted preparation and resume exact requests.**
  A failure after importing a large original must not require another asset copy
  or create a second project. Resume names the same scratch home, brief, native
  worker and import/project request IDs, then verifies actual durable public state.
  It refuses changed input paths or an edited project instead of resetting it.
- **High confidence — require a supplied read-only retained-media root.** Managed
  checkouts may contain large Git-LFS pointers. The preparer uses declared original
  bytes and verifies their hashes; it does not silently download, substitute small
  media or treat a pointer's presence as a usable source.
- **High confidence — retain readiness and annotation gaps explicitly.** Registered
  model status in the new isolated library is observed independently of old proof.
  Human marks retain their source hash/clock; another transcription's words cannot
  be transferred. Preparation therefore stays useful without new inference or
  fabricated word rows, while full caller acceptance remains a separate step.
