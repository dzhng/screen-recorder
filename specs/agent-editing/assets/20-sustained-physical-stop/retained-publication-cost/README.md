# Retained camera final publication

Status: one qualified closed-source measurement. A fresh verification checkpoint
on private APFS clones of the saved physical camera source took 38.552 seconds
to prime. Camera publication then took 4.052 seconds, preserving all 6,145
ordered pictures, exact support, timescale, binding, origin and pause evidence.
Both final readers resumed beyond source origin, and no fallback was reported.
The donor stayed unchanged.

[Verification](verification.json) and the [archive](evidence.tar.xz) retain the
actual process, executed source, complete receipts, reader ranges and source pins.
Full cloned media and mapping remain private under the pinned original manifest.
Root integration matches the two executed consumer files byte for byte; no second
measurement was needed. The opt-in consumer lives with the existing stop-scale
harness and adds no ordinary-suite run or production hook.

The test uses the debug executable and a checkpoint primed on already closed
media. Priming is reported separately and does not reconstruct live verification
progress. The timed operation excludes physical input drain, primary publication,
source-receipt publication and app/service quit. This is no physical deadline or
release-time speedup claim. Fresh container bytes differ while pictures and clocks
match; a retained terminal journal suffix also permits different receipt JSON.
The producer's whole-process time includes post-exit hashes and is an upper bound.

This result answers the remaining camera-proof cost question. A changed signed
candidate's physical confirmation must still prove complete shutdown through the
original ten-second deadline. Repeating this closed-source measurement or adding
a profiler would not supply that missing physical evidence.
