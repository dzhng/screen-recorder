without recomputing it. The receiver has no available RNNoise capability or
composition-audio executor. It adopts the original implementation identity and
recipe, rebinds revision references, and delivers the same full and late PCM.
This extends the historical unit-rate/gain transfer proof; those gates remain.

[Verification](verification.json) pins the worker, harness, command and retained
files. The archive includes the generated stereo source, public request/reply
trace, donor prepared WAV, transferred package and delivered excerpts. The
package copy named `evidence-only` is not opened by the receiver; its actual
admission archive, donor home and source are removed before retained reads.

The transfer oracle is the donor's publicly delivered PCM. Frozen-adapter parity
belongs to the linked-runtime/channel evidence, not this preservation check.
Dry substitution differs; missing, corrupt and replaced learned files refuse
without execution. Adoption cancellation leaves no visible project/assets and
the same request succeeds after restart.

This is a short generated differing-stereo fixture, not speech or listening
approval. The linked worker still contains RNNoise; an unavailable capability and
executor establish retained-read independence, not a model-absent executable.
`model.status` concerns the separate speech-model owner. No new store, queue,
package format or production behavior was needed. Long-output scaling and
combined retiming remain separate acceptance gates.
