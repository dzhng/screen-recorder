# Choices examined

All are sound; none changes product behavior.

- **Medium confidence — supplement the historical cohort rather than replace it.**
  When old scratch speech outputs were gone, source-only guard sheets covered
  every original phrase, while comparison panels used only retained reference,
  slowed and sped WAVs. This keeps unavailable output evidence explicit and avoids
  another speech render or listening request. Historical full-rate images remain.
- **High confidence — retain compressed endpoint PCM after exact recovery.**
  Missing impulse files otherwise force future reviewers to build a processor
  again. The authorized frozen reconstruction matches every original hash, and
  compressed Float32 files now let ordinary plotting run without synthesis.
  Recovery invokes the existing recipe; it does not implement another algorithm.
- **High confidence — align separate trace panels and shade source guards only.**
  Overlaid traces hid each other, so paired plots share axes but separate recipes.
  Source marks show what was selected; output word positions are not guessed from
  the speed ratio. The charts therefore clarify evidence without upgrading it to
  proof of missing audio or intact words.
