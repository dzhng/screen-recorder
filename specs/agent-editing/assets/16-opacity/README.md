The worker receives numeric opacity operations. Activation windows and retained
normalized evaluation ranges stay in authoring; one service-boundary projection
removes those fields from native metadata. Direct native harnesses use the same
projection. This preserves the strict native request check without a second
curve evaluator. Picture/movie recipe identities advance for this wire contract.

The public journey compares eight nonlinear cubic samples with independently
calculated constant-opacity controls. Every PNG is byte-identical; the eight
post-split PNGs are also exact. The compiler tests additionally cover trim,
retime/move, duplicate, old-source replacement refusal/reset, normalized padded
replacement, typed clock validation, cubic extrema and tap-aware boundaries.

composition has 158 passing tests. Type checks and targeted service/CLI builds pass.

existing still-image membership/layout mean-RGB tolerance of 12 code values:

0.164–0.826. Maxima reach 18 and 7 respectively. This is not byte-exact encoded
color acceptance and does not close slice 06's stricter profile gates.

the prior integrated image/pointer worker. Reports and artifact hashes are in
