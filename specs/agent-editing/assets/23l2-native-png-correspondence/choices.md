# Choices

- **Sound, high confidence — isolate transport qualification.** The corrected
  source-color owner is tested in one newly linked worker, keeping every other
  native object and existing worker untouched. Only saved composition requests
  enter its JSONL transport. This proves that transport reaches the correction
  without rebuilding or replacing production/native/model artifacts.
- **Sound, high confidence — reuse the complete selected-source references.**
  Each returned physical sample selects its already retained RGBA reference.
  Every byte is compared; reference pictures are not rendered again. Equal image
  samples reuse the existing complete packet rather than adding another large
  archive. Current PNG hashes and actual transport bytes retain this run's identity.
- **Sound, high confidence — permit only truthful publication differences.**
  Corrected PNG encoding changes file size and fresh paths. Those two receipt
  fields are verified against the actual output; all remaining metadata equals
  the original native receipt. This does not relax any clock/sample/pixel oracle.
