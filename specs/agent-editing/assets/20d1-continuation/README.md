absence is proven. Public calls acknowledge finalizing while that attempt works;
status reads remain available. Failure persists on the existing recording as
`finalizationError`, and explicit stop starts a new attempt. Cancel drains the
worker while retaining ambiguous source bytes. Library deletion retains its
separate quiescence authority.

The full-service canonical recovery tracer uses the banked 100,000-run source from
`20d-source-budget`, with an idle native-control fixture and the real media worker.
It completed in 254.11 seconds while stop acknowledged in 117 milliseconds and
public status remained responsive. The terminal take has a usable revision and the
original video duration. This is an observation under concurrent compression and
short build work, not a comparative performance benchmark. It does not claim the
banked fixture came from a live capture or the actual publisher lifecycle.

The control receipt omits detailed native interval and pause arrays; existing native
models and source-evidence routes retain them. The actual banked interval arrays
measured 4,177,875 bytes for one role and 8,355,750 for two before the envelope, so
that measurement alone did not establish an overflow. A separate serialization
model with longer coordinates measures an 8,800,307-byte full result and a
325-byte bounded receipt. That model proves control-output ownership, not physical
container feasibility.

asset checkpoint, this change uses format 16 and explicitly refuses an actual
format-15 catalog. There is no migration or same-version layout ambiguity.
