# 12g choices audit

The task fixes policy, ownership and constraints: filler measurements remain
informational, only explicit required labels earn canonical hard enforcement, and
historical evidence remains immutable. No new product decision, unsound choice or
user-only question remains. The following technical discretion was reviewed.

- **Synthetic metadata through the actual CLI — sound, high confidence.** A small
  authored cohort labels two held-out groups and a walkthrough so the evaluator's
  existing evidence branches execute. These are test inputs, not recordings or
  human review. The report's complete values and the process exit prove policy
  behavior; no model or audition runs. The plan left exact fixture layout open.
  Future consumers may use this as a scorer contract test, never as speech quality
  evidence. The reused complete-cohort builder and `unit-test` identities make the
  boundary visible.
- **Reuse the before-run numerical oracle — sound, high confidence.** The original
  failed CLI report contains every count, rate, Wilson interval and boundary
  statistic. The corrected test uses those same numbers instead of recalculating
  a parallel statistical owner. Preliminary expected interval literals were
  corrected from that original report before the green run; the implementation
  formula and thresholds never changed. The plan required unchanged measurements;
  the exact oracle location was implementation discretion.
- **Scratch preservation matrix — sound, high confidence.** Additional CLI cases
  remove one evidence field or introduce one measured failure while retaining low
  filler rates. They reuse the authored test factory directly, and bank exact
  inputs/results. They add no maintained adapter, alternate scorer or runtime
  configuration. An initial missing-runtime field also changed model identity;
  that refusal is retained, and the corrected case removes network provenance
  without changing the compared configuration. No production correction follows
  from a malformed probe.

Internal field/helper names and packet layout are cosmetic discretion.
