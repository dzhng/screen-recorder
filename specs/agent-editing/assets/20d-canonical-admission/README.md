# Canonical source admission

This checkpoint binds source support to verified canonical media, rather than to
accepted callback counts or a canonical-looking filename. The existing native
publication/materializer owners verify the exact journal prefix, represented PCM,
occupied runs and file identities. Source export projects those verified runs using
the shared native microsecond projection. Acquisition admission freezes receipt
presence and absence and checks the verified media hash before fresh or cached asset
publication. Working packed files never enter the asset inventory.

Project packages retain the small publication receipts alongside their acquisition
journal. Transient readiness and durable adoption share native revalidation, the
bounded normalized-evidence reader and the binding constructor. The journal's actual
layout determines the verification path. Publication-backed asset metadata is checked
against the existing native probe through the same admitted descriptors; matching
media hashes alone cannot authorize a different source clock.

## Evidence

`verification.json` identifies the frozen worker, source hashes, focused commands and
scope. `manifest.json` verifies every member of `evidence.tar.gz`. The public harness
is [capture-canonical-admission.mjs](../../../../packages/test-harness/editing/capture-canonical-admission.mjs).
Its offline source is the existing banked writer PCM, published through the real
materializer/publisher fixture. It exercises CLI/MCP import, complete and late/tail
source reads, project placement, project-package export, donor removal, native package
readiness, adoption, relocated PCM and service restart. Delivered samples match the
independent authored waveform exactly at a 100001 us phase and fractional run edge.
There is no listening, codec-quality, live-device or writer-activation claim.

Retained negative controls include accepted-only tails, missing proof, an altered
receipt with recomputed inventory hashes, a layout downgrade, duplicate roles,
changed binding support and a forged canonical origin with matching binding changes.
The forged origin originally reached ready; descriptor-backed native metadata
verification now rejects it. Removing the digest guard fails the cached/fresh import
gate. Restoring claimed-layout dispatch fails all three portable admission regressions.

The one-microsecond controls describe two distinct contracts. A synthetic schema1
journal seam is merged by its documented rounded-endpoint tolerance; its initial
failed oracle and complete outputs are retained as a domain distinction, and no
legacy tolerance changed. An already-normalized one-microsecond external mask reaches
the native reader and suppresses exactly the expected sample. The public asset
selection API has no arbitrary external-mask input; public schema2 coverage concerns
whole native-frame gaps, not an invented public one-microsecond capability.

## Remaining rollout

This closes canonical acquisition and **project-package** admission only. The separate
recording-domain processed-package inventory/inspection path is covered by the
subsequent [recording package checkpoint](../20d-recording-package/README.md). Stop/recovery
continuation, typed zero-represented outcomes, actual callback/layout activation and
large-work operation-specific deadlines remain owned by 20d. Source verification now
consumes native work during package readiness, including legacy journal dispatch;
existing cancellation propagates through the worker, but this checkpoint does not
claim the current short worker deadline covers the measured large fragmented case.
