# 23k planning choices

These choices belong to the prospective [source consumer bridge](../../slices/23k-source-consumer-bridge.md).
They authorize no execution in the documentation pass.

## Sound — medium confidence

### Separate actual pages from the historical ready movie

When: 23k planning, 2026-10-01.

The choice: navigate actual service pages and dispatch the selected empty project's
preview action, stopping that action before service work. Then connect the same
controllers to a scripted navigation page containing unchanged historical project
metadata and complete saved preview replies. A new empty project's ID cannot be
substituted into an old movie receipt: that would manufacture ownership evidence.
The gap: saved 25b pages are empty, while saved ready movies belong to different
explicitly configured requests; 23h verifies the owners separately.
The reach: acceptance proves actual metadata and composed historical consumption
under separate labels. Live default-preview readiness remains a later claim.
Verdict: sound because it tests the missing composition without generating media
or pretending the historical token is a current lease. Confidence: medium.

## Sound — high confidence

### Use an empty public catalog fixture when paging input is insufficient

When: 23k planning, 2026-10-01.

The choice: if an existing owned current-format fixture cannot yield a continuation,
create six explicitly configured empty projects through the public API. Their
complete create replies provide expected values for two controller pages. The
alternative, writing rows into SQLite or wrapping saved project.get metadata as
an allegedly real page, would skip the service that owns ordering and cursors.
The gap: the banked 23j catalog has one project and 25b retains no nonempty actual
page. The reach: only metadata fixture setup is added; no media, models, migrations
or automatic capture-to-project behavior follows. Verdict: sound because the
public writer establishes honest current-format paging inputs. Confidence: high.
