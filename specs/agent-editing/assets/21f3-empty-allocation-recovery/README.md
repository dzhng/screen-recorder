# Empty allocated-source recovery correction

The [allocated-source contract](../../slices/21f3-public-camera-selection.md#empty-allocated-sources)
owns this correction. An allocated take can stop before a journal exists. Native recovery can
close that source unavailable only when its owned, private directory is literally empty under
exclusive ownership and the service has already proved native idle and fenced the finalizing
allocation. The directory lock supplies no independent capture-idle proof. No source authority,
journal, snapshot or media is manufactured; retained unknown or raw members remain a refusal.

`verification.json` pins the source and separately named RED, final test and native-worker
runtimes. `source.tar.gz` preserves native package sources and manifests; `external-code.tar.gz`
preserves the exact cached FluidAudio CODE, its generated bundle accessor and bundled lexical
resources. Cached generated RNNoise C is pinned separately and remains preserved in the original
3c source archive. The traits-disabled worker does not link the cached NeMo binary. These builds
constructed no model and ran no inference. Original workers and packets remain unchanged.

The first control reproduced `JOURNAL_UNAVAILABLE` through actual native Wire and failed for
the expected missing closure. The final focused gate covers primary/camera, lost-reply retry,
directory-only preservation and retained-member, authority, ownership, permission and cancellation
refusals. The existing native default capture suite also passes. Complete requests, replies and
specimens live in `cohort.tar.gz`; build and gate logs remain complete alongside it.

The initial RED production source is the pinned base commit. Its two test-only changes are
reconstructed from the authored patches in `red-test.swift.txt` and `red-main.swift.txt`; they
were not copied separately at build time. The RED executable itself is frozen and pinned.
The first candidate exposed the `/tmp` ancestor alias and was refused without any file writes;
that complete failure is retained, but its intermediate source/runtime was not separately pinned.
The final implementation retains the selected leaf identity while allowing canonical ancestor
aliases, matching existing directory leases; a selected symlink still refuses.

Actual service retry/reopen and atomic selection remain the integration owner's gates. There is
no new physical synchronization, hardware, live-stop, audible, model-quality, UI or installed
acceptance. In-flight directory replacement and EIO fault injection have no new experimental
claim; existing descriptor identity checks and outer operational refusals remain in force.
