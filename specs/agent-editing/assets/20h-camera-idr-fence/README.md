# Complete-IDR camera fence authority

The [slice](../../slices/20h-camera-idr-fence.md) owns the new fixed question.
[The report](report.json) separates actual retained-byte inspection from the
frozen native prototype and [the scoped execution](execution/README.md). A codec drain fence is a hypothesis about the whole
preceding coded sequence; it is not a tail chosen to make a sample pass.

[The preparation manifest](manifest.json) pins primary-standard identity, exact
source/control/plan/runtime bindings and complete byte facts. Its archive keeps
reference sources and saved-data controls; it adds no maintained parser, harness
or production architecture. Unsupported syntax is refused rather than guessed.
The primary standard itself is identified, without duplicating its large PDF.

Logical payloads, clocks, complete format metadata and committed support are
compared separately from physical file placement. Snapshot copying and closure
relocation remain explicit. Neither codec bounds nor complete closed bytes prove
active append invariance or either canonical digest.
