## Contract and ownership

One retained recording receives the same caller-authored cuts through the actual
recording and project public APIs. Complete delivered pictures must agree with
each API's declared selection rule and the saved source interval mapping. An edit
join does not require the two selectors to choose the same physical picture.
This is primitive correctness, not an editorial assignment on the recording.

The existing recording timeline owns concatenated spans; composition owns project
placement, frame cells and source mapping. Existing native selectors own nearest
sample selection and physical containing support. The test observes those owners
through public requests; it adds no compatibility interpreter, new picture owner,
catalog migration, policy adjustment or automatic treatment. A genuine production
defect requires reporting and a bounded reslice before changing implementation.
