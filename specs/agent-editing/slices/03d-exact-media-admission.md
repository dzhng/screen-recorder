## Decisions and review

Three independent drafts considered two atomic slices, five risk-ordered stages,
and nine API stages. This plan combines early authority measurement and a reusable
carrier checkpoint, then makes the consumer cutover atomic: splitting probe and
consumers would require temporary rejection or rounded authority. The final pass
is targeted preservation rather than a second implementation architecture.

Delegated: internal helper naming, smallest existing harness extensions, exact
fixture frame counts chosen to exercise both rounding directions, and ownership
of parallel implementation files if needed. Not delegated: field domains, clock
origin, floor rules, scope, compatibility, output quality or new DSP policies.
If container support contradicts complete decoded support, stop that cutover and
reslice the observed ambiguity first. Human feedback can change creative quality
acceptance; this precision correction has an objective complete-PCM verdict.
