## Contract

project public entry points. Successful requests replay before stale-head checks;
changed arguments conflict, competing writers commit once, rejected mutations
leave complete state unchanged, and undo/restore create fresh revision identities.

The test chooses fixed technical intervals, not words or editorial removals.
Spans and complete composition documents are different representations. Compare
their retained source mapping and guarantees without introducing a compatibility
interpreter or requiring identical generated IDs.

format22 recipient already owns the exact same hash-named source media and genuine
stream metadata; copy that catalog and its canonical files, then create the test

[The harness](../../../packages/test-harness/editing/cutover-state.mjs) owns the

both services then stop and restart before replay. Native calls are fenced before
forwarding to the unchanged frozen worker and restricted to startup metadata and
owned workspace recovery. Unexpected work fails the gate.

The picture stream defines the retained recording source clock. Narration has an
explicit 48,675µs origin and its own container support. The oracle verifies both

from 23a is not erased by this state case.

## Acceptance limits

Complete public values, documents, receipts and history pages are retained, not
only counts. The replay-disabled scratch producer fails on restarted replay;
the untouched producer passes. Existing absent-clip removal is an intentional
no-op, so late-batch refusal uses a genuine foreign processing-step error.

This closes the paired public state correspondence for the edit/history matrix
row. It does not authorize an installed switch, retirement of legacy owners,
another recording, a new model run or a personal editing deliverable.
