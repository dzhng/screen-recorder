# Historical task-note evidence

The retained [public fixture](public-notes.json) reads explicitly transferred
notes using actual project/revision socket metadata. It then explicitly changes
only the controlled project's canvas and resumes the same notes file. The chosen
revision remains available, current head differs, caller rationale remains
verbatim and history is unchanged by resume. A declared preview file was never
transferred and remains missing; the fixture counts zero native-worker calls.

This proves historical-state distinction and non-preparation through the public
metadata seam. It does not prove a media artifact's contents or audiovisual
quality, nor does it add a project-package transport mechanism. File transfer
is separately exercised by the portable notes test: notes and a task artifact
are copied explicitly to another directory; the same notes hash remains and
only actual file presence changes. The product's existing package transfer
contract is unchanged and its final joined journey is owned by the parity end
check.
