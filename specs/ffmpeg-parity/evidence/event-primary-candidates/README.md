# Temporal provider and reference candidates

This inspection selects no provider, category or confirmation cohort. The
[primary operands and hashes](inspection.json) preserve the upstream documents,
code and complete original temporal label table in a lossless archive. No weights
or source audio were acquired, and no model ran.

PANNs' DecisionLevel models return framewise scores, unlike the previously tested
Cnn6 clipwise recipe. Their pinned code matches the source already retained by
the earlier research. Code and weights have distinct MIT and CC BY 4.0 authority.
The candidate weight still needs actual downloaded-byte identity and a frozen
runtime before execution.

An expanded score array does not establish timing precision. The original helper
repeats each reduced-resolution score across multiple frontend positions and
pads the tail with its final score. A later recipe must retain that original
meaning and qualify physical support; it cannot advertise the frontend hop as
independent event resolution. Convolution and smoothing context are separate
from score spacing.

AudioSet's primary strong-label release describes complete human event annotation
with start/end regions and provides separate Laughter, Applause, Gasp and Clapping
identities. Its annotation license does not license the original YouTube
soundtracks. Source availability, per-file permission, actual bytes/channel and
the parent-video-to-excerpt clock remain prerequisites. No clip is selected from
these labels yet. VocalSound's primary category inventory lacks Gasp and Applause;
its sighs and sniffs cannot substitute for those labels or supply timed endpoints.

The next useful action is source admission and a new frozen development and
untouched confirmation protocol. Existing failed event results remain failed.
Neither a richer output array nor new labels permit reusing consumed confirmation,
relaxing the original gates or claiming interval quality without actual evidence.
