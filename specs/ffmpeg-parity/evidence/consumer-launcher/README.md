# Portable direct-tool handoff checks

The [manifest](manifest.json) binds complete runner/judge reports, case inputs,
skill/reference hashes, portable CLI and container identities. Extract the lossless
archive into scratch storage to inspect failed calls and judgments as well as passes.

Imported-footage planning and unavailable native treatment each pass twice with
the revised direct-tool reference. The initial GIF task fails once before that
revision and twice after: ordinary Mac next-step summaries omit the unknown-command
recovery required by the bar. The final task explicitly asks for that recovery;
both fresh trials pass with the same bar. This tests a different requested scenario,
not evidence that the skill revision alone fixed spontaneous recovery explanation.
The changed task and earlier failures remain retained.

The passing recovery scenario preserves failed discovery, verified-kit launcher
refresh, both tool version checks, source retention and actual-file verification.
The main consumer skill keeps one fallback pointer; the media reference owns
direct-tool checks and links to the installation procedure. These portable checks
prove schema use and requested handoff behavior, not a macOS GIF, installed launcher,
release execution or reliability for every novice request. The CLI bytes predate
the latest-main release-version changes; final package acceptance remains separate.
