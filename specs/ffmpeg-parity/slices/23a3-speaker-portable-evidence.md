# 23a3 — Portable source speaker observations

Status: required after [source publication and reads](23a2-speaker-source-evidence.md).
Question: **Can export, package open and adoption retain the exact source speaker
observations without a model runtime or another inference?**

## Contract

The existing portable resource/inventory owner carries a typed speaker generation
dependency. Preserve complete source/model/decoder/support identity, exact
observation clock, anonymous invocation-local rows and lossless native receipt
bytes. An imported slot remains local to its original generation and never names
a person. No package read, export or adoption prepares, downloads or invokes a
speaker model. Original media and native evidence bytes remain unchanged.

Export inventories ready source observations for every selected source, including
retained history, through the existing bounded package admission. Missing or
unfinished required speaker evidence refuses honestly. Package open validates
metadata, inventories and SHA before exposing ready source/project reads; adoption
publishes copied artifacts, typed references and imported readiness together under
the existing transaction/lifetime owner. An uncertain acknowledgement uses the
existing replay contract. A failed/canceled adoption cannot leave a partial ready
speaker generation or borrow donor files after closure.

The package schema change is explicit and coordinated with the existing
compatibility owner. No automatic migration, untyped companion, silent field
drop or compatibility alias is permitted. Keep the intermediate 23a2 package
refusal until export/open/adopt can all preserve this dependency.

## Test-first proof and exit

Use controlled source execution or the retained accepted native output. Prove one
source observation, overlapping anonymous intervals and all 375×4 native score
bytes survive export → read-only open → adoption → donor removal → restart.
Compare source rows and repeated/retimed/partial project projection against the
original generations. Ready reads require no model/runtime. Exercise tampered
receipt/hash, missing inventory, conflicting existing generation, cancellation,
lost acknowledgement and failed adoption recovery through real owners. Preserve
complete comparison operands before gates. Run only the affected package/lifetime
controls; no assembly, preparation, inference, rendering or personal media action
is justified by this persistence change.

Remove the intermediate speaker package refusal only after these controls pass.
Review shape, diff and docs and obtain an independent Codex review before the
checkpoint. Update the owning speaker plan with this required pass; portable
preservation belongs inside the current parity spec, not a future wish list.
