optional model preparation/runtime/jobs. Core retains additive source/channel

Project evidence uses the existing exact occurrence projection. Do not change
transcripts, select edits, acquire providers on read or substitute a hosted model.

A real accepted labeled event and negative source, repeated/retimed occurrences,
partial coverage, unavailable model, generation replacement and stale reads prove
the shared contract. Preserve core/catalog/package behavior and exact source
identity. Every category keeps its own gate and limitations; no aggregate green
status can close a failed category. Inference supplies evidence only. No audio
playback on the personal machine or user-media editing demonstration.
