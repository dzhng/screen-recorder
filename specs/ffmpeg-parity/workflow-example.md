# Novice workflow example

Illustrative acceptance target, not an executed edit. The user selected ordinary
imported footage first and will test the demo after the spec. Specification work
uses isolated component checks only.

## User brief

> Turn these clips into a clear, concise video. Keep the important content, remove
> obvious failed takes and dead time, and add readable captions where people speak.

## Expected agent behavior

1. Load the consumer skill, verify installation and discover actual schemas and
   readiness. Resolve ordinary settings without requiring editing-stack knowledge.
2. Inventory only supplied footage. Read compact transcripts when speech exists;
   inspect pictures/audio around uncertain choices. Silent footage needs no ASR.
3. Explain the approach within the brief. Ask only about unresolved content or style
   choices that materially change the result. Evidence never authorizes an edit.
4. Apply explicit non-destructive edits, selected treatments and caption placements
   to a managed project. Do not apply every processor merely because it exists.
5. Inspect changed joins and representative output, repair observed defects and
   record review coverage. Never claim listening or viewing that tools cannot do.
6. Deliver a new file from the chosen revision with concise changes and limitations.
   Retain task-side project/revision/artifact pointers for the next session.

## Extra task

> Also give me a small GIF of this moment.

Use the simple skill pointer to bundled FFmpeg for a non-core output. Direct
outputs are standalone files; import and place them explicitly if needed in a
managed project. Preserve originals and inspect the requested excerpt.

## Acceptance

The person does not choose filtergraphs, models or millisecond fades. The agent
preserves meaning, chooses routine settings, uses supported capabilities and
checks actual output. Fresh-agent trials test this consumer experience separately
from macOS execution tests. End-to-end editing is a future user-run/release check,
not a prerequisite to finishing this specification.
