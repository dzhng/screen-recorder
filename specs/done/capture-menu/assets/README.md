# Reference authority

[reference-manifest.json](reference-manifest.json) pins the user inspiration,
selected concept and exploration artifacts with their original hashes. The sharp
concept renders define geometry and hierarchy; their names, thumbnails, times
and status text are illustrative. The supplied image inspired the look but does
not override the later Design A choice.

The original Capture references and final images below are historical. The
[compact concept](compact/concept-a.png) supersedes their Capture layout;
[its provenance](compact/reference.json) records the selected single-row source
layout and corrections to generated artifacts. Native material and its continuous
arrow silhouette take precedence over a generated approximation of glass.
Library retains the original concept's separate sidebar/content structure.
Native font rasterization, window chrome and source icons are platform/data
differences; fixture comparisons retain point/backing-scale observations without
rescaling native evidence to agree.

The [final production-view renders](final/) use synthetic idle facts in both
appearances. They supplement the original geometry comparisons under `evidence/`;
they do not imply live capture readiness. The historical quadrant map and
clickable concept are frozen exploration provenance, not active build prompts.
