# Ordered processing rationale

[Composition](../../../packages/composition/README.md) owns typed target stacks,
routing and temporal compilation. The [processor declaration](../../../packages/composition/src/processing.ts)
and public schemas own available settings. This record explains why the contracts
are separated; the [release-era specification](https://github.com/dzhng/screen-recorder/blob/c08e0bd8e10903d482232818ccfffaf1d653555a/specs/done/agent-editing/processing.md)
retains the original declarations and implementation ladder.

## Routing is not linked editing

A processing group determines how children combine before its ordered stack runs.
A synchronization group determines which occurrences an edit affects. Neither
changes source identity, and changing a parent cannot silently retime its children.
Independent parameter lists per member would make the combined-result contract
ambiguous, so a target owns one explicit ordered stack.

Dry inspection excludes that target's stack while retaining the processing that
produced its input. An after-step tap excludes subsequent stages. Raw source reads
remain separate. Preview, inspection and export must evaluate the same compiled
meaning rather than growing their own effect order.

## Activation and identity

Bypass retains settings and position; an empty stack is identity. New occurrences
do not inherit arbitrary clip treatments. Replacing media preserves compatible
target-owned settings, while source-attached content has its own replacement
rules. Incompatible source-bound treatment requires explicit repair or reset,
not silent removal of a step.

Temporal activation uses the target's declared clock. Cuts restrict the existing
curve rather than restarting it. A pure split changes structure without changing
visible or audible output; new IDs are not DSP resets. Copying can preserve copied
siblings' mutual continuity without sharing state with the originals.

## Stateful domains

State continuity is engine-owned membership in a compiled current-revision domain.
It is neither a caller-selected group nor an inherited ancestor configuration.
Derive retained inputs and ordered prefixes before selecting the requested output
window. Trim and removal change the domain; cropping old prepared output or using
a hidden whole-source prefix would retain material the edit excluded.

Parent domains follow structural contributions while activation follows authored
windows. Incompatible membership and domain cycles require the editor's explicit
normalization/receipt rules; independent imports cannot rely on an unseen repair.
Numerical split/window parity, changed-input invalidation and exclusion isolation
must be proved at actual execution, separately from authoring validity.

## Selected resampling context

Resampling is a different state boundary from authored learned processing.
[The context owner](../../../packages/composition/src/audio-context.ts) derives runs
contiguous in source and project time under compatible mappings. Source or ancestor
availability holes break support; a harmless clip split or downstream gain change
does not. Removing material must exclude it from filter input.

Requested windows do not crop the full relevant filter domain. Native decoding
intersects that domain with occupied source support and consumes its absolute
sample origin. Seeking through excluded media does not permit those samples into
the filter. Synthetic edge padding is a resampling rule, not permission to use
unrequested speech as context for another processor.

## Preparation and portability

[Managed preparation](../../../packages/core/src/prepared-audio.ts) uses the existing
job lifetime outside edit transactions. Complete dependency identity includes
upstream context, ordering, rendition and selected implementation. Missing backends
refuse rather than producing dry output, upgrading a model or downloading at render
time.

Retain exact model-dependent published results, not only a random seed or mutable
cache. A portable revision must play and undo using its retained dependencies
after the donor cache disappears; regeneration can require explicit preparation.
Original sources and generated bytes keep their independent asset authority.

The [verification guide](../../../packages/test-harness/editing/README.md) locates
reference and public-boundary proof. A lower noise floor or ASR agreement cannot
establish natural speech. Keep raw samples and separately identified listening
copies; noise reduction and ambience placement remain independent caller requests.
