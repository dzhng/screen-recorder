# Cross-owner media contracts

This record explains distinctions that must survive component changes. The
[operation registry](../../../packages/protocol/README.md) owns public shapes and
availability; [composition](../../../packages/composition/README.md) owns exact edit
meaning. The [release-era declarations](https://github.com/dzhng/screen-recorder/blob/c08e0bd8e10903d482232818ccfffaf1d653555a/specs/done/agent-editing/contracts.md)
retain the original schema sketches and operation matrices.

## Identity is not location or intent

[Core](../../../packages/core/README.md) distinguishes immutable bytes, acquisition
context, an occurrence and a revision. Reusing source media does not merge the
identities of its uses, and imported provenance does not manufacture a capture
role. Admission snapshots and validates owned bytes; later workers cannot substitute
a mutable donor path.

Capture closure, written journal mappings, verified canonical media and managed
adoption supply different authority. A submission or positive duration is not proof
of durable support. Source origins preserve inter-stream offsets; independently
zeroing every track would erase real synchronization evidence.

Evidence reads do not mutate a composition. [Editorial control](architecture.md#editorial-control)
explains why detection, processing suggestions and convenience defaults cannot
select additional edits. A generated asset likewise does not place itself or
silently stretch to a requested target duration.

## Time and retained content

Exact source/project mappings survive sampling labels, cuts and retime. Query
clipping must not change a word's retained fragments or promote a partial word
to a whole one. Search matches ordered occurrences within a track; overlapping
tracks cannot be interleaved into an invented phrase. Missing support interrupts
that adjacency instead of becoming captured silence.

[Structural editing](../../../packages/composition/src/edits.ts) owns ordered batch
meaning, linked expansion and anchor partitioning. An attached child must not be
shifted twice when its parent also moves. Linked scope preserves offsets; a caller
choosing independent scope must see the resulting partition. Replacement cannot
retarget source-attached content to unrelated media without an explicit operation.

Project cut events describe source-mapping transitions, not scene detection or
proof that a composite visibly changed. Query edges cannot manufacture cuts.
Physical availability gaps remain source facts, while parameter changes belong
to processing rather than that editorial event category.

## Compiled pictures and sound

A range preview retains the full project's sampling and curve phase. Its leading
picture can depend on an occurrence that ended before the requested interval;
clipping visible support cannot select a new source picture. Physical sample support,
codec packet timing and authored project time remain distinct.

[Processing](processing.md) owns combined inputs and state domains. Source silence,
missing samples, explicit padding and encoded tail capacity cannot be conflated.
Normalization, ducking or output fitting must be an explicit supported treatment.
Resolved settings participate in derivative identity; presets do not authorize
unsupported codecs or silent geometry changes.

Text retains literal content separately from source evidence. Font dependencies
bind admitted bytes and face identity so an ambient fallback cannot change a
portable revision. Correcting captions does not synthesize replacement audio or
install fonts, and admission does not infer redistribution rights.

## Transactions and uncertain outcomes

[Core transactions](../../../packages/core/README.md#transactions-replay-and-lifetime)
commit revision, references and replay receipt together. Native work and model
preparation stay outside that transaction. An uncertain answer is not permission
to create another mutation identity; replay must recover the original outcome.

Pagination and artifacts stay bound to query, revision and dependency generations.
A continuation refers to its initial immutable selection while freshness is
rechecked across publication. A changed query cannot repair an old cursor, and
refreshing metadata must prove it belongs to that same manifest.

[Delivery](../../../apps/cli/README.md) preserves complete response and media leases.
[Publication](../../../apps/service/README.md) pins external intent through recovery
and acknowledgement loss. Cancellation joins resource owners before cleanup can
remove their files. Portable adoption owns its dependency closure instead of
borrowing a donor library, model cache or open inspection handle.

## Evidence does not generalize itself

[Release acceptance](release-closeout.md) and [verification tools](../../../packages/test-harness/README.md)
separate numerical correctness, decoded appearance, listening, physical inputs and
resource measurements. A successful schema, frozen picture hash or codec metadata
cannot substitute for a different observation. Retained quiet audio is selected
source material; neither a denoised signal nor subtraction proves speech-free
source separation.
