and 3/4 `um`. All four missed fillers and every unmatched word remain in the

[Selection](selection.json) keeps the original manually checked transcripts,
annotation labels, complete source WAV/PCM identities and row 84's `bo-`/`b-`
ambiguity. The density-enriched cohort is one human actor rereading conversational
scripts; it supplies no population prevalence, spontaneous multiple-voice,
verified model-unseen, acoustic word-boundary or join-listening claim.

[Verification](verification.json) owns the source revision, complete test parquet,
durable media authority, producer and actual native close. Both metadata-only

The successful execution performs one recognition per utterance, with no supplied
text or edits, network denied and retained model homes write-denied. Every model
file remains unchanged. Native resident memory is an observed worker metric,
not a complete OS/CoreML memory certification.

The [lexical scorer](../../../../../packages/test-harness/speech/evaluate.mjs) shares
normalization and ordered matching with the full evaluator. It accepts text-only
references and returns diagnostic counts; it cannot produce a timing/adoption
pass. The original evaluator retains its explicit timing tie rule. Identical
repeated copies lack independent physical occurrence attribution here. Current
saved-only reevaluation reproduces all 24 recorded diagnostic objects; the
verification record distinguishes that from unavailable dispatch-time helper bytes.

[publisher card](publisher-README.md) and

manual transcript-checking method. Full parquet and extracted audio remain in the
