# Retained sentence alignment preparation

This is isolated preparation for one prospective supplied-text timing diagnostic.
It supplies no alignment result, speech-quality acceptance, recipe adoption or
product change. The accepted Parakeet recognizer remains unchanged. The complete
command and hash records are in [manifest.json](manifest.json); the persistent
namespace retains the prepared files and complete new runtime byte inventory.

The same historical Qwen3 ForcedAligner revision, eight model files and 56 package
versions were recovered. The fresh Python 3.11 environment owns a copied existing
standalone interpreter. Historical Python patch and distribution binary hashes
were not retained: version equality and current byte pins do not establish the
original environment's byte identity. The accepted voice runtime was only read;
its missing dependencies and different versions make it unsuitable for this case.

The first CLI invocation rejected two mutually exclusive destination flags before
retrieval. Its original error is retained. The corrected invocation uses isolated
cache environment variables and one destination; it is the only actual model
retrieval. Every model hash matched before one dependency installation, followed
by a metadata dependency check. Nothing loaded the model or converted/inferred
audio. Commands target the new namespace; the selected original source/read
authorities retained their hashes. This is not a rehash of whole accepted homes.

The prepared text rows contain only the actual 12h raw words, in order, including
opening `Um`. They contain no timestamps or human marks. The independently marked
edges can evaluate a future output; they cannot shape its input.

Source inspection supports the frozen native `media.convertSelectedAudio`
primitive for a separately declared whole-sentence input. Complete original
Float32 mono PCM can produce zero-origin 16 kHz mono PCM without selecting a cut
or applying a treatment. This is not proof that its bytes equal the recognizer's
internal PCM: that payload/hash was never retained. Conversion has not run.

The timestamp audit found no supported production correction. Recognized source
spans preserve the spoken token extents and apply the source projection once.
Mixed signed edge errors and the paragraph duration error cannot be repaired by
one clock shift. The retained punctuation tail already stays outside the spoken
extent. Engine timing accuracy remains unresolved.
