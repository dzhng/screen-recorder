# Admission choices

## Adopted

- Verify every portable acquisition through the actual journal, including a claimed legacy layout. Package metadata cannot choose whether its own proof is checked. Native work during transient readiness is intentional; operation-specific large-work budgets remain a separate rollout obligation.
- Keep normalized record validation and binding reconstruction in their existing evidence/acquisition owners, with transient and durable admission as two consumers. No TypeScript clock or alternative journal parser is introduced.
- Re-probe only publication-backed canonical asset metadata through the already-admitted descriptor. This prevents hash-preserving clock relabeling while retaining the existing generic noncanonical asset policy.
- Copy small proof files into the existing acquisition owner's temporary verification directory, removed on completion or by its existing startup cleanup. Canonical media stays descriptor-backed; no new registry, janitor or durable ready marker is added.
- Refuse an admission containing present unverified/corrupt canonical audio before any asset publication. Missing unpublished roles with no canonical file emit no playable audio; independent native role publication remains available.
- Preserve schema1's documented one-microsecond rounded seam tolerance. Exact external-mask behavior is verified separately at the native reader, without claiming an unavailable public arbitrary-mask API.
