# Numerical curve evidence

A flat cubic can turn a tiny lost time remainder into a visible scalar error.
The analytic endpoint and fractional-center tests pin that failure through the
existing compiler. The retained mutation rounds the two phase operands before
subtracting; the fractional-center result loses its expected nonzero remainder.
The passing implementation subtracts exactly and uses centered coefficients.

The [native conformance journey](../../../../../packages/test-harness/editing/scalar-program.mjs)
feeds the composition owner's numerical program to both runtimes, in debug and
optimized Swift builds. Independent analytic functions test numerical correctness;
matching runtimes alone would only prove that both share the same mistake.
The [verification receipt](verification.json) records that comparison and the
byte-preserved public PNGs from the previously reviewed geometry cohort.
The public gain/audio delivery gate remains in slice16.

The compressed capacity case is a validated composition whose legal normalized
evaluation fractions exceed Int128 sample-conversion capacity. It establishes
why fixed-width native rational refusal would narrow existing input support.
The native program instead receives a stable sample coordinate map derived with
BigInt arithmetic by the shared owner. The contract and finite-domain argument
live in [the prerequisite plan](https://github.com/dzhng/screen-recorder/blob/f362b1f6cf9fa2ae558150a717210ef6a5b09dac/specs/agent-editing/slices/16b-scalar-program.md).

Exact key dispatch and representable bracket adjacency are separate correctness
requirements: an interior cubic key must return its stored value even with a large
easing weight, and a tiny legal phase must not run out of iterations before that
weight is resolved. Both retained red tests fail the incomplete solver. The loop's
ceiling follows binary64's exponent range; normal inputs finish at adjacent
representable endpoints much earlier. The [cost sample](cost.json) includes process
startup and JSON overhead, so it bounds this numerical component rather than
claiming end-to-end audio throughput.

[Combined-build verification](root-integration.json) repeats all 7,023 native
samples and 39 public geometry pictures after integration with the sampling
boundary correction. Focused composition/transcript tests and affected transcript
consumers pass. The first public attempt selected a stale default debug worker
(the workspace app build produces release); its protocol refusal is retained in
[root-stale-worker.log.gz](root-stale-worker.log.gz). Explicit scratch-product
compilation and a new frozen worker resolved that setup error. Encoded quality
remains the separate gate described by the geometry evidence.
