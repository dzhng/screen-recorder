# Registered voice readiness

This checkpoint prepares the fixture's registered voice model through the existing
public `model.prepare` owner in the input preparer's exact isolated library. It is
readiness for the external caller, not synthesis, delivered-media acceptance or
an installed release. The [maintained checker](../../../../../packages/test-harness/editing/acceptance-voice-ready.mjs)
accepts explicit immutable local model/runtime sources and an existing prepared
input file. New evidence directories preserve earlier reports. Ready reuse checks
the same library without repeating adoption.

The sources come from the [exact runtime recovery](../19d-runtime-recovery/README.md).
The checker verifies registered bytes, runtime modes and relative links, and
compares source identities, the original durable prepared tree/receipt and the
frozen native worker before and after. The genuine preparation owner creates its
own managed files and receipt. No ready receipt is copied or fabricated, and no
alternate downloader, provider, model registry or preparation queue is introduced.

The original caller input file keeps its earlier absent-model snapshot. A derived
`caller-ready-inputs.json` accompanies the readiness handoff, retaining the same
brief, asset, clock and edit bindings with the actual public ready status.

The public journey retains missing-runtime refusal, observable progress, joined
CLI/MCP preparation, ready reuse and readiness after reopening the service. The
Models owner returns the actual managed execution paths and identity after that
public proof. Native calls are limited to ordinary service startup; no model
execution, synthesis or transcription is performed. Parakeet remains absent.

A separate project verifies literal `paid` text anchored through `content` placement
to an audio clip and its source interval, including preservation after a parent
move. Its reference audio is a capability fixture, not generated `paid` evidence.
The eventual caller can use this existing placement on its actual generated clip;
it does not need invented ASR word rows to establish this occurrence. The main
empty fixture project and its revision remain unchanged. The historical narration
transcript remains historical evidence, with no current canonical receipt adopted.

[Verification](verification.json) binds the completed public checks and their
limits. [Evidence](evidence-pins.json) preserves complete replies, both producer
versions, the native journal and terminal processes. The [source closure](source-runtime-pins.json)
reuses the prior exact runtime packet and banks this checker separately. [Review](review.md)
and [choices](choices.md) state the examined decisions. Host-load timing is
unmeasured; this checkpoint changes no deadline and transfers no listening verdict.
