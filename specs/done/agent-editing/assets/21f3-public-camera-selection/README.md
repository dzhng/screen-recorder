# Public camera selection and source admission

This packet verifies the isolated atomic selection checkpoint through the actual
app controller, service host, native capture, CLI/MCP transport and acquisition
owners. Only physical input is prerecorded. The caller explicitly authors the
project, tracks, geometry and placement after source admission; capture creates
no project or layout. [Verification](verification.json) identifies the final
runtime, commands and claims. [Evidence](evidence.tar.gz) retains public exchanges,
original source directories, native requests/results, controls and numeric media.

A selected camera is allocated with its recording/source/device identity in the
existing capture transaction. Both private source destinations exist before input
preparation. The bound camera writer accepts a preallocated destination only when
it is owned, private and empty, preserving retained mapping and unknown members.
Physical closure releases queue priority independently of publication: either
source can become ready while its sibling remains pending or has no usable video.
Receipt identity stays immutable while the latest native observation controls
whether unfinished donor work may proceed.

The actual crash controls kill the controller before ordinary finalization. Native
recovery verifies retained media under the same allocation and admits each source
independently. Acquisitions survive donor deletion, service reopen and portable
adoption after the original home and package are removed. A crash before input
preparation settles two genuinely empty allocated sources without inventing media.
Missing storage still refuses. An original completion followed by a torn tail stays
in generic evidence even when native proves shorter usable support. Missing or
changed private authority, changed journal bytes and substituted canonical input
refuse before any acquisition becomes ready. Private recovery receipts do not
become portable source members.

The final numeric journey preserves the earlier fixture's selected pictures,
clock-derived placement, complete PCM, replacement/undo behavior and relocated
history. All public PNG and WAV bytes equal the already reviewed numeric set.
This explicitly authored specimen omits the obsolete camera prologue and uses
10 ms delivery pacing; ordinary controls retain the producer defaults. The visual
verdict and image set remain in the archive. Enlarged low-resolution replacement
imagery and intentional black support gaps are fixture properties, not image
quality or hardware synchronization claims.

Discovery ordering, empty discovery, authorization reporting and default audio
forwarding are service-boundary controls with scripted native responses. They do
not claim hardware enumeration. Selected capture, refusal, physical closure,
publication, recovery, admission and caller-authored project journeys use the real
controller and native owners. Deadline controls simulate worker work and compare
small and large retained inputs; they establish bounded work budgeting without
claiming elapsed performance. The native default suite and capture-controller
lifecycle race gate preserve the affected neighbors.
