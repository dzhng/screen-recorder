# Durable capture admission

A settled take reserves its source acquisition and existing job before source
files are opened. Each observed identity or absence is immutable across failure,
restart and explicit retry. Temporary access refusal remains retryable; changed
frozen material refuses. The allocated source must match the normalized journal
before publication. Capture creates no editing revision or project.

[The original packet](verification.json) retains controlled source/SQL checks,
regression controls, reviewed source/runtime identities and disclosed historical
raw-log gaps. [The archive manifest](manifest.json) pins its exact payloads.
[The merged verification](merged-verification.json) independently checks those
identities and retains the passing current core build and five-file focused gate.
Its additional logs are pinned separately; the original archive stays unchanged.

These tests use actual catalog, capture, acquisition and job owners with a
scripted native boundary. They establish durable admission and recovery, not
live capture, physical synchronization, media quality or stop performance.
