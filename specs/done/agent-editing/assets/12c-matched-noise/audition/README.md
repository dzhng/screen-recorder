# Optional listening comparison

These four five-second WAVs use the original matched-noise recording cohort:
reference, added noise, conventional filter and learned filter. Each is a separate
constant-gain audition copy targeting RMS 0.05, with exact gain, peak, sample count
and original/output hashes in `audition.json`. No limiter, compression or output
trimming is applied. RMS matching does not promise identical perceived loudness.

The user answered the listening comparison on 2026-09-28: **“Learned filter
sounds better.”** RNNoise is therefore the leading candidate for the subsequent
quality/state experiments. This establishes a preference on these particular
RMS-matched clips; it does not separately certify every consonant, boundary, noise
type or stack operation. Protected-word joins and broader listening remain open.
Raw ungained outputs remain the numerical evidence. The app exposes playable
files; the test does not activate speakers automatically.
