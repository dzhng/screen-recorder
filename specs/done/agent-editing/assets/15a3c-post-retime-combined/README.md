gain predict the parent prefix, and that prefix must match before the frozen C
RNNoise adapter supplies the learned expectation. This order prevents a shared
wrong stretch or routing prefix from passing as learned integration evidence.
The familiar sentence and the previously accepted excerpt are reused; this is
an execution gate, not a new listening fixture or quality judgment.

retimed occurrence, while the captured native state input still contains that
occurrence and prepares it once. Exact late PCM therefore checks that learned
history includes a finished retimed contribution. The empty clip stack, overlap,
held gain, authored window and zero-mix plateau exercise the existing parent
owner together. Wrong-order, reset-at-zero and process-before-mix expectations
all differ from the correct output. A deliberately wrong prefix expectation
fails after the two independent dry stems pass; this is oracle sensitivity,
not a production mutation.

Ordinary, prepared, split, reordered, bypassed, undone and historical reads
match their independent PCM. Full and ranged preview audio separately match
AAC encoded from independent PCM in an otherwise plain unit-rate reference
project, using the same range and settings. The wrong-order reference's decoded
AAC differs. Full durable export is byte-identical to full preview. These are
matched encode/decode delivery checks: lossy AAC is not equated to lossless PCM,
and a cropped full encode is not equated to an independently encoded range.
