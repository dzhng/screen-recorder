# Combined picture inspection verification

A separately built frozen native worker combines timeless still decoding and
transparent acquisition-ancestor exclusions. [Verification](verification.json)
records its exact binary hash and three passing real journeys: acquired project
gaps, native stills, and retained project screenshot indexes. All 22 prior project
PNG outputs are byte-identical. The still journey also retains its four matched
legacy video outputs, all 16 image orientations and eight refusal cases.

The complete raw reports are compressed without changing their JSON bytes:
[acquisition](acquisition.json.gz), [stills](still.json.gz), and
[project indexes](project-index.json.gz). For example, `gzip -dc acquisition.json.gz`
reads the original command traces and checks; the verification file hashes those
decompressed bytes. Compression avoids another large duplicated printed receipt
set while retaining exact machine evidence.

The [acquisition picture](../10d-acquisition-pictures/README.md),
[still image](../10d-still-image-native/README.md), and
[public index](../10d-project-index-public/README.md) harnesses own reproduction
commands and the prior per-feature references. Root visual inspection of the gap
details and aligned source/preview comparison agrees with the retained fresh review.
No additional visual change is claimed beyond those reviewed implementations.

This verifies their combined native path; public raw-image routing and project
still composition remain separate unimplemented gates at this checkpoint.
