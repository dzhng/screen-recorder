# 24z12 choices audit

No unsound or user-only choices remain. Internal names, placement, description
shape and conservative numeric accounting were delegated by the approved slice;
these are recorded here so integration can distinguish discretion from widening.

- **Conservative JSON delivery — sound, high confidence.** A valid JSON document
  that fits the existing raw buffer can still be deferred when twice its UTF-8
  size plus the complete envelope exceeds the response bound. Computing exact
  quoting would require reading its lease first. The estimate leaves the original
  token live, so a caller can read it without losing evidence. This follows the
  approved pre-consumption contract and makes no new raw cap.
- **One selected socket, no instance claim — sound, high confidence.** A call that
  discovers a service carries its explicit path and cancellation signal into each
  automatic read. If that listener disappears, later items report ordinary
  connection errors instead of rediscovering or launching an app. Restart token
  expiry remains the service's authority. The test observes one initial health
  probe and an actual listener loss, not an invented instance identity.
- **Cost from current owned failures — sound, medium confidence.** A service can
  refuse a media read because its request slots are full, and Node can include
  the selected path in a pipe error. Admission budgets the larger fixed diagnostic
  and the socket diagnostic, with the longest current failure-code width and
  normal empty details. The packet pins those writers and Node's actual formatter.
  This constrains future changes to this closure: widening its error bodies needs
  a corresponding budget review. There is no parallel registry or output truncation.
- **Buffer equality — sound, high confidence.** The first successful PNG path
  exceeded the original test deadline during a deep framework comparison of eight
  million buffer elements. Native Buffer.equals checks every byte and preserves the
  oracle while removing that unrelated assertion overhead. The initial timeout is
  retained; neither fixture bytes nor test/hook deadlines changed.

Other choices are cosmetic. Production owns no new endpoint, cache, token store,
service batching rule, worker configuration or external dependency.
