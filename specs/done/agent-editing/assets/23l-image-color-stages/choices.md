# Choices

## Sound — observe the existing graph boundary in a standalone process

When the saved PNG enters the actual compiled graph, the graph image is private.
The probe briefly observes the existing Core Image call, passes every original
argument to its original implementation, and restores both implementations. This
makes the compiled graph available for the other publication comparison without
copying its filters or adding a production hook. Exact type encodings, call counts
and restoration evidence qualify the observation. The gap was access to this
existing private boundary; the reach is this isolated diagnostic only. Confidence:
high, with root's explicit review and authorization.

## Sound — retain complete public samples and disclose the private boundary

A lazy graph has no public discrete half-float pixel plane. The diagnostic retains
the input and publication CGImage provider bytes, terminal BGRA rows including
padding, profiles/attachments and lossless PNGs. The unchanged color-managed pixel
reader compares every normalized RGBA sample. Inventing private half-float pixels
would suggest an observation that never occurred. These records can locate a
change in the tested PNG path; they cannot supply the missing historical movie
buffers. Confidence: high.

## Sound — preserve the failed compile and prepare a distinct successor

The first Swift compile used a C function spelling that the actual SDK imports as
a property. It exited unsuccessfully before any image operation. Its source,
commands and error remain untouched. A separate successor changes that one spelling
and otherwise keeps the same graph, objects, owners and limits. This preserves the
failure rather than rewriting the source that produced it. Root separately
reviewed and authorized the successor. Confidence: high.
