# Prepared capacity choices

## Sound — high confidence

### Use two authored boundary plans with declared duration and deferred execution

A tiny imported WAV is accompanied by an explicit probe result describing a long
source interval. Two authored project windows compile to the last frame count
accepted by the native WAV writer and the next frame. The existing queue startup
barrier permits the supported request to queue; the unsupported request must
refuse without adding a job or temporary reference. The renderer never runs.

The task specified the quota contract and existing seams but left fixture layout
unspecified. Explicit original frame counts and microsecond windows independently
guard rounding at admission; deriving the fixture from the TypeScript cap would
let a wrongly enlarged cap move the test inputs and hide the mismatch. The probe
is the existing external metadata edge, not a new provider or production hook.
This decision enables fast admission coverage while physical multi-GiB output
remains outside this fixture's claim. Verdict: sound; the test proves the actual
consumer refusal and supported queue behavior without resource-heavy rendering.
Confidence: high.
