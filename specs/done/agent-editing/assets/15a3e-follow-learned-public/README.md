# Public follow into learned ordinary and prepared audio

The accepted public follow snapshot supplies the independent input to this
integration gate. The committed [14e verification](../14e-public-retiming/root-verification.json)
authenticates its full report, which authenticates the frozen PCM and historical
edit response. [Input identities](inputs.json) bind the retained package and WAV.
After public package adoption, the gate restores the exact historical document
and checks it against that response. The package's current output gain is not
part of the restored follow snapshot: that snapshot has no audio processing.

Current ordinary output must match the frozen whole-project dry PCM before the
shared frozen C adapter produces the learned expectation. This makes a changed
follow result fail before it can become its own learned oracle. The original
public integer clocks are preserved; no approximation of the older rational
native fixture is needed.

An explicit output RNNoise step processes the restored project. The late ordinary
request runs before full learned preparation, after the follow occurrence has
ended. Captured native input excludes that occurrence from ordinary delivery but
includes it in learned-state history, with one retained follow preparation. Late
and full output, a prepared excerpt crossing the follow end, and the MCP late
audio attachment all match their independent expectations. An independent reset
at the late boundary differs. Substituting that wrong expectation fails the late
sample assertion after dry parity passes; the restored expectation passes. This
is oracle sensitivity, not a production mutation.

The existing [public runner](../../../../../packages/test-harness/editing/denoise-runtime-public.mjs)
selects the [small follow fixture](../../../../../packages/test-harness/editing/denoise-follow.mjs)
with `--follow`. It reuses ordinary/prepared delivery and the existing C adapter;
its default unit-rate journey is unchanged. No production code, schema, model or
new processing owner changed. This closes only the scoped public ordinary and
prepared follow-to-learned join. Earlier movie evidence remains distinct; no
follow-plus-learned movie cross-product, speech quality, spatial quality or
listening acceptance is claimed.

[Verification](verification.json) records replay and source identities. The
retained package and compressed dry WAV are portable inputs. The authenticated
evidence archive holds final CLI/MCP exchanges, captured native requests and
responses, delivered media, C inputs/raw outputs, the wrong-reset failure and
source snapshots. Identical files share the manifest's `storedAs` member.
Build the service and CLI dependencies before replay and supply the existing
native worker and frozen C adapter; replay needs no old temporary directory.
