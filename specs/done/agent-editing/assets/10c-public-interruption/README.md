# Public capture interruption journey

The source continuation schema now accepts the interruption head emitted by the
shared capture reader. The CLI/MCP operation guide describes recorded capture-end
markers, their left-supported boundary ownership, and qualified unavailable
termination. Existing recording/package selectors and ordinary capture point
semantics remain unchanged.

The actual first public run caught the missing schema field: the service returned
a valid source cursor, then rejected that cursor on continuation. The retained red
report and protocol regression pin this integration failure. The corrected public
journey adopts real media and journal files through acquisition import, reads both
CLI and MCP, deletes the donor directories, and inspects retained authority.
Synthetic journals explicitly exercise reliable completion, interruption, absent
completion and damaged or contradictory endings; the original recorded journal
continues to supply real cursor/geometry preservation evidence.

`termination-source.json` records the public coverage qualifications and exact
clock conversion. The video starts at a nonzero container origin; its interruption
closes the selected source endpoint. The shorter audio retains the capture facts
without receiving a marker relocated to its own end. `termination-project.json`
retains adjacent opening observations whose clip IDs sort before the prior ending
clip, page-one continuation, repeated/retimed occurrences, partitioned windows and
historical continuation after a head change and service restart.

The expanded journey retains the existing raw-coordinate, pause/geometry,
unavailable-support, tied-track, empty-page, late-window, cache-loss and historical
checks. Source rows come from the separately native-normalized fixture output;
termination expectations come from the authored journal facts, and project times
come from the independent authored plan. Removing interruption rows at the actual
service response boundary makes this oracle fail. The unmodified runtime passes
again afterward; `mutation.json` pins the temporary compiled-only mutation.

Frozen transcript paging and phrase-search preservation also passes on the same
shared runtime hashes. That journey uses retained native transcript output and
local verified model files; it is not a fresh inference or model-download claim.
The compact reports preserve ordered trace runs and original report hashes; the
frozen configuration and calls retain the speech boundary. Protocol, service and
CLI tests, six-package builds and type checks pass alongside the actual journeys.

This is public capture evidence acceptance, not physical capture interruption or
source scene/project-cut acceptance. Scene and cut categories remain explicitly
unsupported. The [core boundary rationale](../10c-capture-interruption/README.md)
and [native provenance proof](../10c-acquisition-lifecycle/README.md) own those
separate layers of the contract.
