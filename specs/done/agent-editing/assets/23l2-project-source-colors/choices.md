# Choices

- **Sound, high confidence — normalize the decoded video boundary.** A video clip
  enters a project PNG with the same source-picture colors as a raw frame. Every
  requested graph operation still runs. FrameImage owns the existing conversion;
  higher working precision alone did not change the measured mismatch. The final
  rule applies to every available video reader, with no identity/source shortcut.
- **Corrected, high confidence — leave ImageIO pictures alone.** The initial
  authorized all-media normalization also rendered still images. Both small
  CoreMedia709 source tests were already correct, and extra rasterization could
  quantize higher-precision inputs early or force unnecessary full-size work.
  Root narrowed the rule to decoded CV video; the still map and raster work are
  removed. The superseded candidate remains named in verification.
- **Sound, high confidence — distinguish the tests that caught the bug.** Both
  small CoreMedia709 ramps preserved pixels on old objects. The saved actual-video
  mismatch owns red/green; the permanent small test is a preservation neighbor.
  No fixture writer, private source injection or invented video clock was added
  merely to manufacture a different regression authority.
