# Captured-source lifetime

Fresh public deletion and discard share source admission's retirement scope. They
fence and join unfinished managed-donor imports, including explicit imports through
aliases, before native cancellation or directory removal. Ready acquisitions retain
their own originals, evidence and caller-authored project history after donor deletion
and service reopening. Verified audio cleanup preserves canonical media; operational
failure remains explicitly retryable and missing proof retains working inputs.

The retained native worker accepted a stale directory descriptor and deleted the
replacement at that name. The isolated current-source worker fixes that observed
failure: the selected entry must match the supplied descriptor, and removal uses
that descriptor. Both moved original and replacement survive refusal. Missing targets
remain idempotent. The old worker is unchanged and is not evidence for the fix.
