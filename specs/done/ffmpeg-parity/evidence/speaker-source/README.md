# Source-bound speaker PCM evidence

The [root receipt](root-integration.json) binds integrated source admission to an
actual native selected-channel observation and a source-format regression. The
complete small operands retain the synthetic source, expected/actual Float32
bytes, clock receipt and unchanged source. No model runs or personal media are
part of this checkpoint.

The complete stereo-to-mono control went red when the prior decoder published
channel one after that channel ceased to exist in the source. The fixed sink
opts into the existing source-format policy before decoding and refuses without
an output. The initial gapped control is retained separately; its support
refusal did not reproduce the channel bug and was not accepted as the regression.

The original proof covers a sixteen-kilohertz source. The additional
[48k source operands](rate-48k/wire-operands.json) use the existing narration
fixture, with the actual native origin and explicit channel zero. The one bounded
call produces exactly480000 finite, nonzero Float32 samples at16k for30seconds.
[Checks](rate-48k/checks.json), [binary/source provenance](rate-48k/provenance.json)
and [complete PCM](rate-48k/pcm.tar.xz) retain that scope. This is resampling/tool
execution proof, not a new model-quality claim or a perceptual judgment.

Public source jobs/reads now use these existing native and durable owners.
Portable preservation is verified by the final service ownership checks. Speaker runtime
setup uses explicit local inputs; the app does not distribute it.
