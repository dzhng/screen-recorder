# Portable consumer acceptance

The [frozen manifest](manifest.json) binds the complete trial archive, CLI bytes,
Docker image, source revision and dirty-input hashes. Extract into a new scratch
directory to inspect full runner/judge receipts, control checks and build logs.
Failed reads, calls and judgments remain evidence; none are truncated or omitted.

The initial prose planning tasks failed exact identity retention. Explicit skill
pins alone did not fix that outcome. The final task requested a printed selection
template and request skeletons with placeholder identities, making the same
acceptance requirements observable in concrete artifacts. Both final planning
trials passed. GIF routing and unavailable-treatment handling separately passed
twice. The earlier GIF judge input-limit error is an infrastructure failure,
resolved by sharing identical complete output strings rather than truncating them.

These trials establish scoped skill/schema behavior in Linux containers. They
do not prove macOS execution, an installed release, media quality or reliability
for every novice request. The CLI operand predates the integrated loudness
contract; final relocated-release acceptance remains a separate gate.
