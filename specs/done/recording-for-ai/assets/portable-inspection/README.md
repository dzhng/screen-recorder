# Portable inspection evidence

[Native relocation](native-relocation.md) is the current generated checkpoint:
source, scene and retained-index readers reproduce shared inspection results after
the original library and media are removed. Public package handles, safe archive
extraction, export admission and accepted transcript integration remain separate.

The earlier [source-page proof](source-pages.md) isolates normalized timing/query
semantics. The [audio planning receipt](audio-plan.json) isolates explicit moved
media paths and the shared AudioInspection planner. Those narrower receipts do not
claim complete package independence on their own; the native checkpoint builds on
them without another timeline, source clock or catalog.

The corresponding [14b plan](https://github.com/dzhng/screen-recorder/blob/2e1028cddc3f89d58018a4ebcbc8895b28a78ae1/specs/recording-for-ai/slices/14b-portable-inspection.md) records the
shared owners and remaining package lifetime/export boundaries.
