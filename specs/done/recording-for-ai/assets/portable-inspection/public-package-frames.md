## Verification

The durable fixture is [package-public-frames.mjs](https://github.com/dzhng/screen-recorder/blob/cc5d7a9fee578758eeadffe662eff0778556d7df/apps/macos/tests/package-public-frames.mjs).
It compares native PNG bytes and timing/pointing metadata with the shared
materializer for an arbitrary annotated timestamp absent from the retained index,
clean frames, crop/downscale, a cut join, sparse/pause context and included history.
CLI output and MCP image content carry those same bytes. This is transport parity,
not a claim about a model understanding the image.

Forty distinct sequential requests pass the existing output and job-metadata
capacity. Repeats reuse an available image; reclaimed results regenerate with new
identities. Held deliveries survive pressure and deletion of a real same-ID library
recording. Closing one of two opens revokes only its deliveries before their TTL;
restart invalidates the remaining process-local handle. Archive hashes are unchanged
and all owned service groups are reaped.

A separate worker-boundary fault proves explicit retry removes the failed output
and publishes the next attempt. A fixture-only constructor barrier confirms a real
native media process is stopped; package close fences new requests, waits for its
terminal process event, then revokes reads and cleans its workspace. No library
job rows are fabricated for this work.

The retained-output matrix additionally pins outputs to descriptor capacity, proves
a retryable limit retains charges, releases enough descriptors for the actual native
source/output/identity reads, and then succeeds. Existing failed-cleanup tests retain
charge until confirmed cleanup; unknown-identity create failures still require close.
