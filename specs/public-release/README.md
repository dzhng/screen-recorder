## Inherited product boundaries

Preserve local storage and local transcription, manual deletion, CLI/MCP inspection,
and exactly two exports: video only and the complete processed package. Public
distribution does not authorize hosted recordings, remote MCP, accounts, telemetry,
payment processing, or drawing tools.

## Open before implementation

support commitments, optional diagnostics, and any compatibility or data migration
requirements. No choices in these areas have been made yet.

## Proposed acceptance evidence

updates preserve access to existing recordings under the explicitly chosen data
policy; both export formats work; documented support and recovery paths match the
released behavior.
