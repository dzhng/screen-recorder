# Speaker feasibility: retained failures and partial successes

The public contract needs stable anonymous speakers, simultaneous speech and honest
word attribution. A loaded model alone cannot establish that contract. These frozen
research bundles preserve every tested failure; none authorizes production labeling.
They contain observations, protocols and replay sources, with no media, weights,
installed runtime or build output. Compressed observation operands use Git LFS.
Reported peak RSS belongs to the inference process; separate CoreML/accelerator
services and system caches are outside that accounting boundary.

[Original preservation and continuity](handoff-evidence/README.md) reproduces the
historical short-window output exactly and passes the three-speaker return/silence
controls. Its four-speaker control misses required simultaneous speech.
[Alternative recipes](alternative-evidence/README.md) preserve the low-latency and
Nemotron failures, including separately frozen calibration choices. The
[Community-1 trial](fluidaudio-evidence/README.md) preserves native endpoint refusals
and merged identities. Model preparation and network-denied loading succeeded;
provider quality remains failed.

Each bundle owns a read-only `replay.mjs` accepting the repository root. Replay
checks retained operand hashes and recomputes metrics through the existing scorer;
it performs no acquisition or inference. [Integration receipts](replays.json)
record successful root replay. Successful replay means the reported successes and
failures reproduce, not that the provider passed.

Keep the frozen DER, identity-confusion, overlap, speaker-count and resource gates.
A future candidate must first pass independent short controls before a costly
continuity run or runtime packaging. Do not hide missing overlap as unknowns,
clip estimates into support, fit a threshold on confirmation data, or infer a
speaker from camera presence. The live slice owns the remaining work order.
