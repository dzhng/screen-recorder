# Slice 06 choices

## Sound — use admitted controls to check structural edits

- **When:** slice 06 implementation checkpoint, 2026-10-05.
- **Choice:** prove timing through the persisted project owner using externally
  supplied stream and font probe facts. For example, a two-second source is
  placed into one second of project time, then one fractional frame is removed.
  The real project owner commits the edit, projects both surviving source ranges,
  splits attached captions and compiles the remaining animation. Probe facts
  replace only the native decoder admission boundary. An alternative would first
  decode real footage, introducing native setup and execution while exercising
  the same deterministic structural calculation.
- **Gap:** the spec delegated generated controls and internal verification
  organization; the follow-up explicitly allowed the persisted owner when a
  socket fixture was impractical. A socket fixture needs additional native probe
  plumbing but supplies no additional source-mapping oracle for this patch.
- **Reach:** this checkpoint proves authoring and persistence, not actual media
  decode, rendering quality or ASR. Later real-media acceptance must not cite it
  as evidence for those claims.
- **Verdict:** sound. The changed owner only admits exact request ranges; all
  downstream timing is exercised unchanged, and the final real-media gate is
  preserved separately.
- **Confidence:** high.

No public policy was invented. Exact fraction representation and validation,
range union, synchronization refusals, animation phase and integer-only controls
outside removal all reuse the approved contract and existing owners.
