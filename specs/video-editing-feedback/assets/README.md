# Frozen planning inputs

[Provenance](provenance.json) pins the source revisions and every retained project file. [FEEDBACK.md](../FEEDBACK.md) is an exact byte copy of the complete source feedback; annotations belong elsewhere.

[Session excerpts](session-excerpts.json) contain exact selected public messages/tool inputs with source record indices, not a complete transcript and not newly verified media evidence. The original JSONL hash is retained without copying its 35 MB of session state.

[Reference workflow](reference-workflow/) freezes relevant QA, generation/reproduction scripts, project decisions and selected historical reports. These are comparison inputs; current production owners must not call them as a parallel backend.

[Research receipts](research/sources.json) preserve fetched primary-source identities and excerpts. Documented upstream capability is not a local execution pass.

Actual video/audio derivatives belong under the repository's fixture owner and follow [the fixture contract](../fixtures.md). The planning snapshot itself contains no new source observations.
