# Independent lexical scout — refused prerequisites

The [protocol](protocol.json) was frozen before the first recognition call, with
SHA256 `b96a9b766a28c29ed8f8b98c9fa4e417a1c3913d8c8566a9a395a798ae27384e`.
It reuses all nine complete unlike-microphone WAVs and their original clock
origins. Each source is independently recognized by the prepared first-class
Parakeet model through the native speech operation, with inference networking
denied. This is actual native inference, not a public service readiness claim.
The native binary was copied into scratch and pinned before work; no mutable
build output was shared or new model downloaded.

[The report](report.json) retains every candidate and refusal. None of the three
source pairs has even one shared five-word phrase in the selected transcript
sets. The three-checkpoint lexical prerequisite therefore fails for every pair.
Several windows contain no recognized words. That is a provider observation,
not proof of physical silence, absent remote bleed or missing speech everywhere
in the original recording. These selected excerpts do not prove whole-source
synchronization impossible.

No timing inference followed this failed prerequisite. No source relationship,
edit, retime, camera choice or provider promotion resulted. The protocol's
prospective native CTC cell bounds describe coarse conditional measurements;
they do **not** replace the original known125ms/maximum2ms synchronization
control or justify a clock within80ms. A future candidate must pass the original
precision and separated-anchor/drift gates, or remain refused. Accepted10B
alignment alone cannot manufacture shared speech or give sample-precise sync.

[The scout runner](../../../../../packages/test-harness/editing/synchronization/lexical-scout.mjs)
owns recognition and inference-free replay usage. Replay binds the report to
[the frozen bundle](bundle.json), verifies complete WAV and recognition bytes,
then compares the complete recomputed report. The raw recognition, requests,
native responses and logs stay here; model weights and runtime binaries do not.
[Verification](verification.json) distinguishes successful preservation/control
checks from failed real lexical gates. [Review](review.md) owns the independent
verdict and scoped cleanup findings.

## Next hypothesis

Discover a real mixed/reference track that independently contains utterances
from multiple isolated microphones. Inspect the full original stream inventory
and source clock/edit facts first. Freeze a bounded mixed-reference lexical
bridge protocol and known-delay, wrong-clock, repeats, missing-support and
continuous/discontinuous-drift controls before inference. A discontinuously
edited master must remain a collection of separately evidenced constant-offset
segments; no global offset inferred from equal duration, no inferred edit or
automatic retime. This is the next research step, not an accepted recipe.
